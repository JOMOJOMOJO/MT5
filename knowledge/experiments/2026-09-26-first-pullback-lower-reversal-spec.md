# 上位足転換後の最初の押し × 下位足転換：検証定義案

状態：研究仮説。2026-09-26時点で新戦略の実装・期待値検証は未実施。今回の売買EA修正は表示・診断・最適化準備のみ。

## 問い

「上位足の下降構造が上抜けで転換した後、その最初の押しが起点を割らず、下位足が上昇構造へ転換したとき、取引コスト込み期待値は正か」。波の呼称ではなく、発生時刻と当時観測可能な情報で定義する。

M5は説明上の名称であり実験では親TFを明記する。M4とM5の記録を混ぜない。Close/ヒゲの価格系列も固定し、別系列として比較する。

## ピボット

候補足iの価格X_iに対し、現行互換の高値は左L本すべてより高く、右R本すべて以上。安値は左すべてより低く、右すべて以下。これは左厳密・右同値許容であり、両側厳密ルールと区別する。

候補時刻t_iと確定時刻c_iを保存する。c_iは右R本目の足の終了時刻。連続した通常足ならc_i=t_i+(R+1)Δ。休場・欠落時は実際の足の時刻で計算する。

研究では `structure_price`（Closeまたはヒゲ）と `wick_high/low` を別に持つ。終値で認識し、ヒゲ下にSLを置くことも可能だが、事前に定義し混同しない。

## 親構造：P0, H0, P1, P2

1. 時系列の交互ピボットで、直近2高値が切り下げ、直近2安値も切り下げ。最後の安値をP0、突破対象の最後の戻り高値をH0として固定。
2. 親足終値が初めてH0を厳密に上回る。判定は足確定後。これは下降構造否定/上昇候補であり、上昇トレンド確定と同義にはしない。
3. この突破以降の最初の確定高値でH0を上回るものをP1とする。P0→P1を表示上のWave1とする。
4. P1後の最初の押しを追う。価格がP0以下に達したら構造無効（同値の扱いを現行の厳密下抜けと変える場合は別版）。研究の基本版は現行互換でP0未満を無効とする。
5. P1以降の最初の確定安値P2がP0より高ければ親HL確定。P1→P2をWave2と呼べる。

**「最初の押し」には2つの別仮説がある。混ぜない。**

- A：親HLの確定時刻c(P2)以降だけ下位シグナルを利用。
- B：親HL確定は待たず、P1が既知で、P0を割っていない押しの最中に下位シグナルを利用。

Bの過去のエントリーを、後で親HLになった例だけに絞ってはいけない。これは未来情報による選別になる。失敗した押しも全て母集団に残す。

現行EAは交互列を必須にはせず最後の2高値/2安値を別々に追う。上の交互構造を採用する場合は既存EAと別研究版にする。同種ピボットの連続は置換で過去を動かさず、未成立または別の構造列として明示する。

## 下位構造：L0, h0, H1, L1

1. 親P1の確定後に利用可能な下位下降構造を認識。最後の安値L0と戻り高値h0を固定。
2. 下位足終値>h0の最初の確定足をCHoCH。ここをE0候補とする。
3. CHoCH以降の最初の確定高値でh0を上回るものをH1とする。L0→H1が下位Wave1。
4. H1後の最初の確定安値L1>L0を下位HLとする。H1→L1が下位Wave2。L1を割ればそのHLは失効し、過去のHL位置を更新しない。
5. L1の確定後に、下位足終値が固定H1を初めて上回ればE2候補。次の利用可能Askで入口を測る。単なる途中の戻り高値突破とは別条件。

研究比較はE0=CHoCH、E1=HL確定直後、E2=H1再突破の3段階。現行SkipHL=trueはE0に近く、現行READYは途中戻り高値突破も許すためE2と完全一致しない。

親P1が下位シグナル前に既に突破されていたかも記録する。「初動のみ」と「継続も含む」を混ぜない。現行の初動制限を外すなら別の事前定義にする。

## SLと比較設計

構造否定価格と注文SLは別項目。例えばL1割れで『下位HL仮説失効』、注文SLはL1のヒゲ安値−buffer。親P0割れは『親仮説失効』。起点CloseとヒゲLowを同一変数にしない。

入口の遅れだけを比較する第1比較では、E0時点で既知のL0ヒゲ安値−bufferを共通SLとして固定する。各段階で入口が変わるためR幅・目標到達距離は変わる。第2比較でE1/E2のSLをL1基準へ変え、入口効果とSL効果を分離する。

全E0候補を親ID/下位試行IDで固定し、E1/E2へ進めなかった候補も「未発生」として残す。後でHL/突破した生存例だけでE0を評価しない。後段未発生を、約定したトレードの0Rとして勝率へ混ぜない。

記録：各点の価格/候補時刻/確定時刻、各判断で既知だった点、入口Ask/Bid、spread、SL、TP、コスト、R、MFE/MAE、HL底からの価格上昇幅/R、候補時刻からの遅延、右本数待ちと追加突破待ちの時間を分離。

チャート：P0/P1/P2、L0/H1/L1を個別ID付きで描画。候補足への印とは別に確定時刻の印を置き、ENTRY/構造否定/注文SLを区別する。未来に確定した点を入口時に既知だったように描かない。
