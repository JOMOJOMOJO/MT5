# Wave33 既知の上位足高安帯による環境観測

ユーザー承認: 「そうそう。その認識。実装してみて。」。①の認識は維持し、以前の高安付近への再接近と、目標がその帯を越える関係を観測する。現在の画像を完成済みダブルトップと断定しない。

## 固定する初期仕様

- 対象 EA は独立版 `Wave33ChopDiagnostic` v1.83。原版、共有 Engine/Display/Types/Ledger、①/Fib/往復指標の計算は変更しない。
- LONG は M15/H1 の既知 HIGH、SHORT は LOW。高安の位置時刻は①起点より前、確定を知った時刻は評価時刻以下。SIGNAL より前に公開した PIVOT イベントだけを使う。
- 帯の**片幅**は固定①値幅の 5%（初版の比較用仮定）。全幅は 10%。入力 `InpPriorContextBandFraction` で変更できるが、本作業では最適化しない。
- ①終点が帯の内側、実行可能な予定エントリーが利益方向の帯外縁をまだ越えず、最終 TP がその外縁を厳密に越え、当該水準の時間足の最新既知確定終値が外縁をまだ越えていなければ `BLOCKED`。
- TP/終値の厳密な越境と一致を区別。価格丸め誤差の許容は①値幅×1e-12のみ。
- 全候補を評価し、BLOCKED を優先、次に帯内、次に①終点との距離。同値なら H1、次に新しい位置時刻。欠測候補が既知の BLOCKED を隠さない。
- 選定元の時間足の確定足を、FeedClosed が受理した順に保存する。現在の CopyRates や後続の Engine 状態から過去 SIGNAL を再評価しない。
- データ不足は `UNAVAILABLE` と理由を記録して許可。対象水準なしは `NO_PRIOR_LEVEL`。片幅が非数/負/1超は初期化エラー。
- `InpPriorContext=true` で描画と CSV。`InpSkipPriorLevelRetest=false` が初期値。除外 ON なら診断 OFF でも因果的観測とログを強制する。
- 見送り ON は発注前に `PRIOR_LEVEL_RETEST` で除外し、未発注方向枠を解放。同一候補の再試行を禁止。往復除外も該当する場合は既存理由を優先。
- 発注 OFF の初期値、逆①後プラス決済、手動水準の表示限定を保持。プリセットは A/B 各 ON/OFF を作り、比較で変えるのは本モジュールの除外フラグと run tag のみ。

## 描画と証拠

無限の水平線や左上パネルは追加しない。SIGNAL 時点の選定元の高安の時刻・価格・確定時刻を残し、帯は判断可能時刻から右の有限区間に表示する。元の高安への参照は後から付けた参照と明記。同価格の M15/H1 を独立した反発回数と数えない。

過去全観測を対象とし、任意の探索本数は増やさない。古く消化済みの水準が候補に残る限界と、起動後の前向きウォームアップを明記する。
