# MT5：シグナル消費とテスト完了の監査

[2026-10-08の実例と修正](../../reports/qa/cost_channel_20261008_r2/plan.md)。

- 新バー検知時に処理済みフラグを立てる実装では、市場休場10018の拒否によって当日シグナルを丸ごと失うことがある。新鮮な気配の存在だけでは取引時間内とは限らない。
- 明確な拒否に対する再試行と、送信成否が不明な場合の照合・停止を区別する。同じ注文を無条件に再送しない。
- シグナル発生→送信→拒否→再開・期限切れの対応を監査する。取引数が正、現金損益が合う、だけでは十分でない。
- MT5更新は端末PIDを交代させることがある。独立した実行パス・新規レポート・実行ログを追跡し、最初のプロセス終了だけを完了条件にしない。
- 不具合発見時は旧QA合格も見直す。影響しない完了結果はhashを固定して保持し、影響範囲だけ再実行する。

今回の市場休場修正はシグナル実行の修復であり、戦略の優位性を示す証拠ではない。
