# R上限なしの値動き診断（実行前定義）

2026-10-26 JST。v1.1（下記native SL観測の補正）。ユーザーの「5Rにとどまらずどこまで伸びるのか」に対するオフライン記述統計。EA・テスターを起動しない。実行する場合は開始報告後にCodexが停止し、ユーザーの呼びかけ後に結果確認を行うという希望を保持する。

- 入力：v1.85 annual batch `20261026_100045_50909ab6` の `v185_b_scale_off` 全334入口、native raw deals、既に保存したM1 OHLCと全イベント。既知2020年のみ。部分利確OFF、prior filter OFF、元の初期SLと実約定価格・数量を固定。
- 1Rは実約定価格と初期SLの価格差。価格経路診断なので手数料・swap込み純利益と混同しない。SLを後から狭めない。最大値の計測にRの上限を置かない。
- 主経路：エントリーから参照OHLCが元SLに初めて触れるまで。未到達なら2020年末の最終保存足で打ち切り、未決着と表示する。元TP・逆①利益決済でこの潜在経路を切らないが、EAの設定・ルールは変更しない。これは保有継続による物理的な伸びの参照であって、現行EAで取れる利益ではない。
- native SL補正：元取引が実際に `DEAL_REASON_SL` で終わった場合、そのmillisecond時刻も必須の停止境界にする。参照BidがまだSLを超えていなくても、Ask等により元SLへ到達したことが実約定から分かるため。初回出力にはこの境界がなく、元SL後の反発が最大19.78Rまで混入した取引があった。補正前出力を保存し、最終報告には補正後のみを使う。これは利益に合わせた出口条件の追加ではなく、既知の元SL到達を無視しないデータ整合修正である。
- 固定表示：全期間に加えて1時間・4時間・24時間の経過時点。固定到達水準1/2/3/5/10/20/50Rと、上限なしの最大値・分位点・全件CSV・最大例チャート。最良のTPを選ぶパラメータ探索はしない。
- 元SL到達足の高安順序は不明。直前までの最大を下限、その足の有利側極値も含めたものを上限とする。足の始値でSLを飛び越えた場合、その足の後の有利値を加えない。部分エントリー足もraw millisecondを用いて曖昧性を分ける。
- M1 OHLCは参照価格。Ask系列・時間変動spreadがないため、特にショートのSL生存と利確可能価格は確定できない。「上下限」はこの参照価格経路内の足内順序に関する範囲であり、実約定損益の保証された上下限ではない。
- 逆①は保存イベント中の、同じ時間足ペア・反対方向の新規 `WAVE1_PEAK_CONFIRMED` の最初の判明時刻を併記する。①延長確認・過去のpivot時刻で代用しない。入口後はログ順序も用いる。大きな伸びがこのイベントより後なら現行決済ルールによって取れない可能性があると表示し、厳密なプラス時点決済を捏造しない。
- 元決済以前／以後の伸びと、逆①前後を区別する。保存イベントは元EAの候補生成結果であり、保有時間変更後の全候補・枠・複利ロットを再現するものではない。
- 検証：全334件・重複なし、raw入口照合、初期SL方向、時刻順、全到達率の単調性、SL後の値を加えないこと、LONG/SHORT・終端足順序・gap・部分入口足の合成試験。入力とmethod hashを保存する。元成果物は上書きしない。
- 判定：経路に大きな伸びがあっても利益採用しない。期間・方向別の偏りと打ち切りを含めて説明する。新しいMT5比較と2026保護期間の使用は行わない。
