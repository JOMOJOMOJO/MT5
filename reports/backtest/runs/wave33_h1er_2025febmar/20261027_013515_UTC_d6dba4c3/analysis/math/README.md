## 定義と意味

古い順の確定 H1 終値を C0〜C12 とする。

- net = abs(C12 − C0)
- path = sum(abs(Ci − C(i−1)), i=1〜12)
- ER = net / path
- 往復度 = 1 − ER
- 今回の見送り条件は ER ≤ 0.25 + 1e−12。数学的な境界は往復度 ≥ 0.75。1e−12 は浮動小数点誤差の許容で、条件の最適化ではない。

13 個の実際に存在する確定 H1 終値、12 区間の価格差を使う。直近12経過時間と同義ではなく、休場・日次セッション間の空白を跨ぐ。終値間の移動のうち、始終点に残らなかった割合を測り、反転回数やヒゲの量は測らない。単調上昇・下降なら ER=1、一度の大きなV字も細かな交互変動も出発価格に戻れば ER=0 となる。全終値が同じなら path=0 なので未定義として扱う。

空白を跨ぐ窓は OFF 43行、ON 44行。13終値が占める始点〜終点は12〜61時間。最後の確定H1終端から判定までの最大時間は179,640秒で、2025.02.10 01:54 の週明け判定に該当する。これは既定の観測バー方式の結果で、追加の古さ除外は行っていない。
