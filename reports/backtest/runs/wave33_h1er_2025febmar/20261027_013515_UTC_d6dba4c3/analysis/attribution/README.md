# H1往復度 OFF/ON：約定対応の独立監査（2〜3月）

**1月の改善は2〜3月合計では再現しなかった。** 同じH1条件をONにすると、36件の除外対象が元々は合計プラスであり、合計成績は−6.4196Rから−8.4013Rへ悪化した。3月単体の合計損失減少も、除外した組の質が改善したためとはいえず、候補の空きによる新しい1取引の寄与で説明される。

全ポジションを1件とする集計。元の全数量の初回約定時リスク金額を分母とし、部分利確・最終決済・エントリー手数料・swap・feeを全て損益に含む。2〜3月を継続運用した一つのテストで、月初に資金をリセットしていない。全ポジション・全コストPFは0.8371→0.6334、1取引あたり平均は−0.0904→−0.2334R。

## どの取引が増減したか

- 共通35件：実際の約定時刻・価格・元SL・リスク幅・①起点終点・部分決済と最終決済の時刻/価格/数量比・終了理由・損益Rは同じ。
- 除外36件：20勝16敗。勝ち合計+18.2418R、負け合計−14.6833Rで、**除外した集合は差し引き+3.5584R**だった。
- ON新規1件：+1.5767R。
- 合計差：−3.5584 + 1.5767 + 共通取引の差0 = **−1.9817R**。
- 共通35件中7件のロット/金銭リスクは資金連動で変わった。現金の差は、除外−158.01 USD＋新規67.80 USD＋保持分のロット差−20.76 USD＝−110.97 USD。

H1のSKIP36件と、実際に除外されたOFF36件のIDは今回も完全一致。ただし、ONにだけ出た追加候補があるため、ONを単純な保存済みOFF取引の間引きとして扱うことはできない。

## 3月の見かけの改善と新規取引

2月は除外12件（8勝4敗）が+3.2952Rだったため、その分悪化。3月は除外24件（12勝12敗）が+0.2632Rだったため、間引きだけなら少し悪化していた。

3月7日、OFFは03:37にロング①140を約定し、08:00まで保有、+0.9794R。同日の次のロング①141は06:10に`ACTIVE_SETUP_SAME_DIRECTION`で見送られた。一方、ONは最初の①140をER=0.0281で除外していたため、①141を認識でき、06:44にER=0.3535で約定、+1.5767Rとなった。

この新規1件によって、3月の合計差は−0.2632 + 1.5767 = +1.3135Rとなった。3月の改善を「H1往復度で負けだけを避けられた」と説明しない。

## 終了時打ち切り・会計・注文エラー

`TEST_END / CENSORED_AT_STOP`は両方に同じ1件あるが、①243の**未発注候補**であり、`entry_status=CANDIDATE`、`entry_price=0`、状態`LOWER_COUNTERTREND`。実際の約定ID集合はOFF71・ON36件で、それぞれ全てEXITあり。raw約定の新規数量と決済数量も全件一致。テスター終了による実ポジションの強制決済を欠落させた集計ではない。raw理由にTESTERはなく、全raw IDがFILL IDと一致した。

全ポジションについて、raw約定のprofit/commission/swap/fee総和とEXITの損益、固定当初リスクと`DAYTRADE_RISK_FROZEN`、損益Rが一致する。自由文reasonの未引用セミコロンで列がずれるdaytrade CSVは、末尾の19固定列を保持して復元した。

OFFでは3月20日01:00:29〜55、①196ロングの部分利確に16回`10018 Market closed`が出ている。最終的には部分決済され、当該取引は+0.0830R。OFFの部分利確TOUCH33件・FILLED33件、ON13件・13件。ONは①196を除外している。注文拒否0件とは報告しない。共通35件の決済経路は一致しているため、今回のOFF/ON差を共通取引の執行変更で説明する必要はない。

閾値の探索、EA変更、再テスト、フィルタ採用は行っていない。1月の結果だけによる採用を見送る判断材料となる。
