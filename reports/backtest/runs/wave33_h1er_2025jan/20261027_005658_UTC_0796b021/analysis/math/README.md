# H1往復度の定義と実機入力の独立監査

2026-10-27。対象バッチ `20261027_005658_UTC_0796b021`、測定版 `NATIVE_H1_CLOSED_ER12_025_V1`。EA、閾値、既存資料を変更せず、保存された実機入力だけを再計算した。テスターの追加起動は行っていない。利益・損失の集計は本監査の対象外。

**結論：今回実際に使った39判断時点の計算と時刻には、不一致・未来足利用を検出しなかった。** ただし、往復度は「終値の移動経路の相殺度」であり、文字どおりの往復回数ではない。1/20の部分時間帯は実機の記録窓に一度も含まれず、その時間帯のnative対M5代理系列の一致は未確認である。

## 定義をどう解釈するか

判断時点で確定済みのH1終値13個を古い順に `C0 ... C12` とする。12本の終値ではなく、**13終値・12区間**。

```
net = abs(C12 - C0)
path = sum(abs(Ci - C(i-1)), i=1..12)
ER12 = net / path                         # path > 0 のとき
往復度 = 1 - ER12
ONの除外 = valid && ER12 <= 0.25 + 1e-12
```

三角不等式により `0 <= ER <= 1`。単調な上昇も単調な下降もER=1、往復度=0。始点と同じ価格まで戻る経路はER=0、往復度=1になる。

上昇距離の合計をU、下降距離の合計をDとすれば、往復度は `2*min(U,D)/(U+D)`。往復度0.75は「移動距離の75%が逆向き移動と相殺される」という意味であり、「75%の足が反転」「75%の時間がレンジ」「75%の確率で負け」ではない。小さい側の方向距離そのものは全移動距離の37.5%になる。

この定義の限界は次のとおり。今回の比較に別条件は追加していない。

- 100→106→100の一度の山と、100/101を何度も往復する経路は、どちらもER=0。反転回数を区別できない。
- H1終値の間のヒゲや上下動を含めない。ヒゲが長くても終値が単調ならER=1になり得る。
- 方向を判定しない。強い上昇と強い下降は同じERになり得る。
- 値幅、スプレッド、ダブルトップ、抵抗の有効性を測らない。
- V字転換直後の新しいトレンドでも、過去の逆向き経路が窓に残り、除外されることがある。
- 13個は観測されたバー。休場をまたぐ場合は「直近12実時間」の指標ではない。ギャップによる価格変化も経路に含む。
- path=0は0/0で未定義。ER=0へ補完しない。今回のnative判断では未定義・履歴不足は発生しなかった。

1e-12は、前回監査で発見した「数学的に0.25でもdouble演算で0.2500000000000007となる」境界だけの数値補正。今回の観測ERで閾値に最も近い値も0.0019788918以上離れており、補正の有無で結果は変わらない。閾値探索は実施していない。

## native H1と完全M5代理系列

今回のM5ログから、各時間に正確に12個のM5があり、終了と最大known_atが判断時刻以下の時間だけを独立集約した。この旧方式は `observed_complete_m5_H1_proxy` に対応する。

- 両アームとも38/39判断で、13個のH1開始時刻と価格が一致。nativeの16桁double表現とM5の小数価格の丸め誤差を除き、ERと除外判定も一致した。
- 最初の2025.01.02 08:50だけ、nativeは2024.12.31の過去履歴も使って13個取得した。前向き収集されたM5代理系列には、その時点で13個の完全H1がなく未取得。native ER=0.470556...なので、今回の除外判定には影響しなかった。
- M5の共通部分は旧gold_v180の5515行、旧gold_v190の5069行とも、OHLCおよびknown_atが今回と完全一致。旧記録の期間外まで同じであるとは主張しない。
- Jan20 21:00はM5が6個のみ。最後は21:25、最大known_atはJan21 01:00:03で、完全M5代理系列では除外される。しかしこのnative H1は39判断のどの窓にも出現しない。native側が何を返すかは今回の記録では**観測不能**。周辺の別時刻が一致することを、この時間帯の一致の証拠にしない。
