Rの分母は初回約定時に凍結した全数量の金銭リスク。分子にはエントリー手数料、部分決済、最終決済、スワップ、feeを全て含む。raw_dealsの合計とEXITイベント、DAYTRADE_RISK_FROZENの固定リスクが一致し、全45ポジションは決済済み。

## 何が変わったか

- OFFの29件から、3勝・10敗の13件が外れた。この13件の合計は−6.6549R。
- ONで新たに発生した約定は0件。
- 共通16件は候補ID・方向・①起点終点・約定時刻・価格・元SL・各部分決済と最終決済の時刻/価格/数量比・決済理由・コスト込みRが同じ。
- したがってRの改善+6.6549Rは、今回のサンプルでは13件の除外で全て説明できる。決済方法の変更による改善はない。
- 共通16件のうち7件は資金の違いによってロット/金銭リスクが増えた。OFFの除外13件の実損失は−294.94 USDだが、保持分の資金連動差が−13.46 USDあり、口座損益の改善は+281.48 USD。Rと金額を混同しない。

## シグナルと実取引の分母

H1診断は両アーム39件。ONはALLOW21件（実際に約定したELIGIBLE16件と、元のリスク条件で先に除外された5件）、SKIP13件、WOULD_SKIP_PRECEDENCE5件。今回に限って13件のH1 SKIPとOFFから除外した13実取引のIDが完全一致した。H1判定はbusy・週末・ロット等のガードより前にあるので、他の期間でもSKIP件数と回避取引数が一致するとは限らない。

MT5 HTMLの取引数は部分決済を別件に数えるため、OFF37・ON21件、勝率43.24%・47.62%、PF0.43・0.52となる。本集計の29・16件、勝率27.59%・31.25%、PF0.4126・0.5180は、全ポジションを全コスト込みでまとめた値。どちらも純損益は同じ−536.91 / −255.43 USD。計数単位を明記して使い分ける。
