# 固定する検査定義（集計前）

対象は既存 v1.70 の XAUUSD+・2020年 A=M15/M5、B=M5/M1、完了475取引。EA変更、新しいMT5実行、閾値探索はしない。これらのデータは既に集計済みであり、以下の期間分割を OOS と呼ばない。

主比較は計4つのみ。各 arm で、(1) 値幅拡大群 minus 縮小群の平均 net R、(2) NORMALIZED_COUNTERTREND minus SIMPLE_REACTION_BREAK の平均 net R を求める。値幅拡大は既存の `volatility_ratio >= 1`、縮小は `< 1`。上位足の直近14確定TRの単純平均を、その直前100個の同平均の平均で割る。閾値1、14本、100本を変更しない。認識方式の組合せや方向別の良い部分集合は探さない。

entry-time-only: 元の `trades.csv` に固定された FILL スナップショットと、entryまでに known_at が到来した上位足だけを使用する。認識方式とボラは元 FILL / 上位OHLCから再照合する。net R は実際の費用込み決済 cash / 初期risk cash。TP/SLの名称から勝敗を置換しない。将来MFE/MAE・終了後ラベルを事前特徴には使わない。FILL価格は注文前には未知なので、条件採用には SIGNAL/ORDER 時点への別確認が必要。

各群の年間件数・勝率・平均/合計 net R、2020H1/H2、Q1–Q4の同じ固定比較を提示する。方向は年間の主効果の記述だけであり、方向×方式×ボラの多重絞込みを行わない。

不確実性は1方式のみ: entry月を単位とする cluster bootstrap（12か月を復元抽出し、月内全取引を保持、20,000回、seed=20261023）。主比較4つに対して Bonferroni の同時被覆を意図した98.75%区間を表示する。これは12個の月ブロックを独立とみなす近似で、月をまたぐ依存や非定常性、同一年を既に見た探索バイアスを解消しない。全ての固定比較を提示し、区間が0をまたぐ場合や期間で符号が変わる場合を省略しない。4つを超える主検定や都合のよい追加閾値を増やさない。

原本 events.csv と upper_bars.csv の SHA-256 を既存 `streak_summary.json` と照合し、475件の一意性、元 FILL/EXIT、risk・cash・R、known_at の整合性を再確認する。過去の大監査6719項目を新たに全再実装はしない。生成ティックの1年だけの記述診断であり、利益改善や実運用可否の検証ではない。
