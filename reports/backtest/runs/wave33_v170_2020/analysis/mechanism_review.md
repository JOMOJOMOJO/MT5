# Wave33 v1.70: 連勝・連敗期間を比較するための機構レビュー

対象は [2020年の固定設定実行](../20261022_161002_0ef87d9b/review.md)。A=M15×M5、B=M5×M1。EA変更・追加バックテスト・最適化は行っていない。下記数値は各 `events.csv` のFILLをsetup_idでEXITへ結合した記述集計で、最終的な期間・連勝連敗定義と集計は親分析を参照する。

- A: 429候補、97約定・97終了。B: 1,340候補、378約定・378終了。
- 入力は両方ともRR1、Fib38.2–61.8、上位足終値61.8超除外ON、①延長ON、下位足NORMALIZED_OR_SIMPLE、W1余地最低0.25R、抵抗DISPLAY_ONLY、逆①利益決済ON。
- 勝敗は `execution_net_cash` の正負で決める。Bには `DEAL_REASON_TP` でも費用込み損益が負の1件があり、TP/SLという名称を勝敗へ置換しない。

## 比較すべき4つのエントリー時機構

| 機構 | エントリー当時のフィールド | 連勝/連敗の差として調べる意味 | 解釈上の限界 |
|---|---|---|---|
| ①の継続と再確定 | `wave1_revision`, `wave1_extension_started_at/known_at`, `wave1_peak_known_at`, `candidate_detected_at` | 浅い中間戻りを含む継続波か、最初の小さなスイングで止まった候補か。延長によりFibアンカーと必要な②の大きさも変わる。 | revisionが多いほど良いとは扱わない。①延長は最初の最小Fib到達前に限定され、延長群はもともと異なる値動きを選んでいる。初回起点・候補年齢を共有して比較する。 |
| 下位足の転換認識と待機時間 | `lower_recognition`, `lower_entry_stage`, `lower_structure_known_at`, `trigger_known_at`, `signal_known_at`, `wave2_extreme_time/known_at` | SIMPLEは現在の最深②の確定スイング→最初の反応ピボット突破、NORMALIZEDは逆トレンドの高安構造否定。同じ「ENTRY」でも確認した情報量と待ち時間が違う。 | エントリー後に確定したピボットを足して分類し直さない。SIMPLE/NORMALIZEDの構成差を、ATR・値動きの効率・方向・時間足から独立した効果とは断定しない。 |
| ①までの余地・既知水準・SL幅 | `wave1_room_r`, `obstacle_distance_r`, `nearest_obstacle_source/tf/time/known_at`, `risk_points`, `spread_points` | ①極値へ近づいてから入る場合や、②を遠くに置いたSLによりTPも遠くなる場合を区別できる。スプレッド/SL幅は同じRRでも費用負担が違うことを示す。 | 既知抵抗は全過去スイング高安から最近接を選ぶため、距離が小さいことだけで人間が重視する抵抗と同一とは言えない。価格ポイント幅は変動率に依存するので上位足ATRも併記する。 |

### 今回の記述集計が示すこと

| 特徴群 | A 件数 / 平均R | B 件数 / 平均R |
|---|---:|---:|
| ①延長なし（revision=0） | 69 / -0.246 | 265 / -0.088 |
| ①延長あり（revision>0） | 28 / +0.148 | 113 / -0.124 |
| SIMPLE_REACTION_BREAK | 60 / -0.150 | 213 / -0.154 |
| NORMALIZED_COUNTERTREND | 37 / -0.104 | 165 / -0.027 |

Aの延長群の差はBでは同方向に再現していない。延長群だけを採用する根拠にはならない。下位足認識の平均には差があるが、両時間足・両認識群とも平均Rは負で、この表から認識モードの採用/除外は決めない。連勝・連敗期間の構成差の説明候補として扱う。

勝ち/負けのエントリー時中央値は、①余地A=0.738/0.647R、B=0.940/0.908R。一方、最近接抵抗余地はA=0.0071/0.0076R、B=0.0176/0.0171R。97件/378件すべての最近接抵抗余地が目標1R未満だった。全過去高安を集める現在の候補生成では近傍価格が密集しており、最近接距離だけでは判別力が飽和している可能性がある。水準の時間足・出所・古さと合わせて説明する必要があり、一律の抵抗距離フィルターを提案する材料にはしない。

②押し率中央値は勝ち/負けでA=53.39/55.10%、B=55.78/53.37%。単純な「浅い方がよい」は両者で揃っていない。ヒゲ基準で61.8%超の約定もA30件/B99件あり、上位足終値61.8超除外との不整合ではなく、比較している価格と利用可能時刻が異なる。

## 逆①利益決済はエントリー後の説明要因

`opposite_exit_armed`, `opposite_wave_known_at`, `opposite_exit_requested_at`, `exit_reason` はエントリー後に決まる。勝ち/負けの期間における出口構成と利益の大きさを説明するために使い、事前のエントリー条件へ混入しない。

Aは逆①利益決済6件、平均+0.121R。Bは23件、平均+0.142R。いずれも今回の実現損益は正だった。TPまで到達する約1Rの勝ちと同じ「勝ち1件」に数えると、連勝が続いていても利益の積み上がりが小さい期間を見落とす。したがって、連勝数だけでなく合計R・平均勝ちR・TP/逆①決済の構成を見る。逆①で閉じた取引を、閉じなかった場合の仮想TP到達やMFEで「救えた/損した」と断定しない。

同じ逆①確認が起きても、プラスへ戻らずSLで終わる場合は `OPPOSITE_WAVE1_ARMED` の有無・時刻を実際のイベント順で確認できる。ただし「一度でもarmedになった群」は、そこまで保有し続けた取引を条件としているため、エントリー時点で決まっていた群との因果比較には使えない。

## スナップショットと期間比較の制約

1. 候補IDの最新行ではなく、FILL時点の特徴を固定する。確定判断前の候補・見送りも候補母集団に保持し、約定だけの比較だと何が抜けるかを明記する。
2. エントリー前に利用できた情報はSIGNAL/ORDERスナップショット。FILLは同時点の実際の約定価格・SL幅の補正を含み、注文前に約定価格を知っていたとは扱わない。事前フィルターの話へ進む場合はORDER前情報との差を別途確認する。
3. `known_at <= signal_known_at` を満たす上位足・下位足情報に限定する。①の足位置と知り得た時刻を入れ替えない。
4. 完了ポジションは実際のEXIT時刻と同時刻のネイティブ順で並べる。後から分かった連勝/連敗は記述ラベルであり、その開始を当時予測できたとは扱わない。
5. A/B、方向、既知のH1方向、エントリー前の変動率・価格推移を併記する。H1方向による排除は現在の仕様にない。今回の群を見た後で閾値を選んだり、最も良い小集団を抜き出したりしない。
6. エントリー後の最高益・最大逆行、未来の①延長、最終的な相場高安から期間の理由を作らない。ティック/コストの実現性はネイティブ整合性の別ゲートで確認する。
