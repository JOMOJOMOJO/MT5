# v1.80の追加機能と2020年の観測差

対象は既存の年間ログのみ。旧v1.70の`a_extension_on` / `b_extension_on`と、新v1.80の`v180_a_both` / `v180_b_both`を比較した。EA・設定・検証データは変更していない。

①終点を共有する逆方向候補による取消はAで27件、Bで76件発生した。TP延長はAで22約定、Bで131約定。共通の売買位置に限ると、TP延長群の実現RはAで1.106R悪化、Bで10.006R改善した。ただし新旧は取消とTP延長を同時に変更しており、単独機能の因果効果を確定する比較ではない。新しいTP延長群も両方とも年間合計はマイナスだった。

取消103件すべてについて、同一セットアップにORDER/FILLがログ全体を通じて存在しないことを確認。取消元のWAVE1_BREAKは先行行にあり、同じ銘柄・時間足の逆方向で、既知の固定①終点の日時・価格を共有し、その判断時刻に取消されている。起点・固定終点の既知時刻に未来参照はなく、同方向の候補枠が埋まったために却下されたWAVE1_BREAKを取消元にしていない。

旧版で実際に約定した取消対応事例を参照すると、両パターンとも合計はプラスだった。したがって「取消した数だけ負けが減った」とはいえない。これは旧版で観測した結果の参照であり、新版の未約定候補に仮の損益を割り当てたものではない。新しい約定や枠の変化もあるため、取消単独の効果を上表から差し引くこともできない。

Bの旧のみ32件のうち、取消に直接対応しない1件は2020.07.01 23:20 LONG。新版では同じ起点・ブレイク足の候補が22:05に`ACTIVE_SETUP_SAME_DIRECTION`で見送られていた。旧実績は-2.246R。これも取消と同列に「防げた損失」とは数えない。

## TP延長の観測

TPはシグナル時点で知っている固定①終点を使用する。余裕幅は追加10ポイント・当時のスプレッド・1ティックの最大値。LONGは①高値より下へティック単位で切り下げ、SHORTは①安値より上へ切り上げる。元のRR目標がそれより遠ければ維持する。保有中の未来の高安値でTPを動かす機能ではない。

|観測値|A|B|
|---|---:|---:|
|全SIGNAL|130|507|
|TP延長SIGNAL / TP延長FILL|22 / 22|131 / 131|
|延長した約定 LONG / SHORT|10 / 12|59 / 72|
|延長した約定 勝 / 負|10 / 12|47 / 84|
|延長した約定 合計R|-1.501R|-11.594R|
|延長した約定 純損益USD|-75.25|-535.46|
|延長した約定 平均設定RR|1.586|1.689|
|延長しなかった約定数|65|222|
|延長しなかった約定 合計R|-12.387R|-15.704R|
|延長しなかった約定 純損益USD|-555.40|-718.89|

延長した全153SIGNALについて、固定①終点の既知時刻、終点の手前にあること、元TPより遠いこと、バッファとティック丸めの独立した再計算が一致することを確認した。延長・非延長の群は元から相場条件が違うので、群同士の平均損益は延長の優劣を表す実験ではない。

## 共通売買位置の変化

照合キーは方向＋①始点日時・価格＋上位足ブレイク足日時＋実約定日時。セットアップIDだけでは照合していない。共通432件は全件、エントリー価格・SL・①終点の日時と価格も一致した。金額の損益は資産推移によるロット差の影響を受けるため、Rを中心に比較する。

|共通約定の固定群|件数|旧合計R|新合計R|観測差R|旧勝→新負|
|---|---:|---:|---:|---:|---:|
|A・TP延長|22|-0.395|-1.501|-1.106|2|
|A・TP維持|64|-13.357|-13.357|ほぼ0|0|
|B・TP延長|129|-19.992|-9.985|+10.006|11|
|B・TP維持|217|-17.259|-17.259|+0.0003|0|

旧負→新勝は全群で0件。Bでは11件の勝ちを失う一方、伸びた勝ちの利益増がその減少を上回った。Aでは同じ効果が観測されなかった。Bの新延長約定131件と共通延長129件の差2件は新規に出現した約定なので、共通群の比較には含めていない。TP維持群の微小なR差は数量差と現金丸めを含む。旧・新の全体差を、共通群差と追加・消失した観測約定に分解すると一致する。

## 具体例（意図的に最大改善・最大悪化を選定）

この2件は共通約定のうち、①終点・SL・約定価格が同一でTP延長された群から、R差の最大・最小を選んだ説明用の両極端であり、典型例とは扱わない。時刻は元ログのブローカー時刻で、UTC換算はしていない。

|観測値|改善例：B SHORT|悪化例：B LONG|
|---|---:|---:|
|約定日時|2020.10.12 13:32|2020.08.21 21:21|
|ENTRY / SL|1922.85 / 1923.91|1938.51 / 1935.80|
|①終点|1919.02|1942.10|
|旧TP → 新TP|1921.79 → 1919.16|1941.22 → 1942.00|
|設定RR|1.000 → 3.481|1.000 → 1.288|
|旧結果 → 新結果|TP +0.943R → TP +3.434R|TP +0.978R → SL -1.312R|
|保有時間|1.55分 → 31.48分|154.68分 → 3104.45分|

改善例は短い1R利確から①安値手前まで伸びた。悪化例は旧TPに達したあと、伸ばしたTPには届かず週末を跨いでSLとなり、新版のスワップは-10.86USDだった。TPを少し伸ばすだけでも保有時間と費用が変わる。どちらも旧・新で実際に観測された約定と決済の比較であり、ローソク足から作った仮想決済ではない。

これは既に見た2020年の記述的分析。生成ティックを含む既存ランを使用し、実ティックによる追加検証や最適化は実行していない。v1.70→1.80にはテスターバッチ互換性・ログ項目の追加も含まれる。戦略入力は既存項目では一致し、新しい2機能が有効だが、単独機能の採否を確定するには同じ期間で一つずつ切り替えた固定比較が必要になる。
