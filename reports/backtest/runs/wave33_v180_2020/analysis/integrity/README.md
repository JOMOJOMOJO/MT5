初期証拠金5,000 USD。リスク1%、基本RR1.0。v1.80は連結逆①による未発注候補取消と①手前までのTP延長がON。約定後の逆①プラス決済もON。旧版から利益が改善したのはBで、Aは悪化した。両設定とも費用込みの利益には至っていない。2規則を同時に変更した比較のため、どちらの規則がどれだけ損益を変えたかはこの集計から分離できない。

ネイティブ明細とEAの全FILL・EXITについて、時刻、方向、数量、価格、現金損益、初期SLリスク、R損益が一致した。独立計算した価格損益、手数料、スワップの合計もMT5純損益に一致した。v1.80の440取引に未決済・EXIT欠落・テスト終了による強制決済はない。残高最大DDを明細から再計算して一致を確認した。有効証拠金DDはMT5報告値であり、全ティックの評価損益経路からの独立再計算はしていない。

MT5 PFは約定ごとの符号別現金損益を集計するため、エントリー手数料も独立した負の約定として損失側に入る。往復費用込み取引PFは1取引の全費用を合計した後に勝敗を分ける。定義は異なるが純損益は同じになる。

v1.80 Aの明示費用は手数料-$66.06、スワップ-$42.79。Bは手数料-$446.34、スワップ+$46.06。スプレッドと滑りは約定価格に含まれる。2020年当時の正しい手数料・スワップ条件を再現しているかは未検証。旧BではTPの価格利益+$41.76に対してスワップ-$83.74が発生した1件も独立確認できた。新結果には価格利益がプラスで純損益がマイナスの取引はない。

指定期間は2020.01.01〜2021.01.01。4設定とも全12か月の確定足を確認した。旧新間で各時間足の`upper_bars.csv`、`lower_bars.csv`はSHA256が完全一致した。期間前の確定足が各1本含まれ、別に集計している。休場と履歴欠落の独立した判別はしていない。

**全期間は生成ティックだった。** Model=4を指定しているが、原本ネイティブログに`no real ticks, every tick generation used`と明記され、MT5レポートも実ティック比率0%。4設定とも40,971,991ティック。実ティックによる執行検証が完了したという意味ではない。ログの該当行だけをJSONへ保存し、認証情報は転記していない。

年次実行時のソースと全10ヘッダーはv1.80配置時のハッシュと一致する。年次ランナーで再コンパイルされたEX5は以前の配置EX5とは別のハッシュで、両方を記録した。追加された設定キーとログ用メタデータの差分はJSONに残している。未確認の利益改善や因果効果を保証しない。
