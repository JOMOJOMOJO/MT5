## 見送り条件

LONGなら①起点より前に位置するM15/H1確定高値、SHORTなら確定安値を参照する。評価時点で公開済みのpivotだけを使い、①起点より前に確定済みだったことまでは要求しない。

初版の帯は、元高安から上下それぞれ①値幅の5%（**片幅5%、全幅10%**）。次のすべてが成立すると `BLOCKED`。

1. 固定①終点がこの帯の中。
2. 実行可能な予定エントリーが、利益方向の帯外縁をまだ越えていない。
3. 最終TP（①までの延長・抵抗による上限適用後）が帯外縁より先。
4. 水準の時間足の最新既知確定終値も、その外縁をまだ越えていない。

TPが外縁と同値なら見送り対象外。エントリー・終値が外縁と同値なら「越えた」と扱わない。価格比較の誤差許容は①値幅×1e-12。

複数水準はすべて判定し、BLOCKEDを優先して選ぶ。次に帯内、①終点との近さ、H1、新しい位置時刻の順。基準高安までの距離はSL幅を1Rとして記録する。データ不足は理由を記録し許可する。同一変動をM15/H1で観測しても「2回反発」とは数えない。

## MT5での使い方

テスターのEAを **`dev\\mql\\Experts\\Wave33ChopDiagnostic.ex5`** に選び直す。既に起動しているEAは再開始して読み直す。

| 入力 | 初期値 | 意味 |
|---|---|---|
| `InpPriorContext` | true | 高安帯の観測・描画・CSV |
| `InpSkipPriorLevelRetest` | false | trueにすると対象シグナルを発注前に見送り |
| `InpPriorContextBandFraction` | 0.05 | 帯の片幅を①値幅の何倍にするか |
| `InpEnableTesterOrders` | false | trueならテスター内で注文する |

除外ONは診断OFFでも観測を強制する。往復フィルターとは別設定であり、両方該当すれば既存の往復理由を優先する。初期値の5%は比較用仮定で、収益を見て選んだ値ではない。

テスター注文ON・従来の往復見送りOFFの比較プリセットを用意した。各組で変わるのは本機能の見送りスイッチとrun tagのみ。

## 描画とログの読み方

シグナル時に、元高安へ「事後参照 H1/M15 日時 @価格」を表示する。元高安と①終点を点線で照合し、判断時刻から右へ下位足12本分だけ高安帯を描画する。過去へ戻って付けた参照は、当時すでに存在した売買判断線を意味しない。元高安の確定時刻・評価時刻はツールチップとCSVに保存する。

`BLOCKED` は赤系、ほかの帯は紫系。見送りONで対象なら「見送り: 上位足の高安帯に再接近」。緑のENTRY矢印を出さず、未発注の方向枠を解放する。注文済み/保有中の取引をこの見送り処理で変更しない。

MT5 Common Filesの `<run_tag>_context.csv` に51項目、`_events.csv` に `PRIOR_CONTEXT_FILTER` と、該当する場合 `SKIP / EXCLUSION / PRIOR_LEVEL_RETEST` を出力する。元の時間足・位置時刻・知り得た時刻・価格、帯、最終TP、基準足終値、全候補の位置情報を残す。設定と計算バージョンは `_config.csv` と入力ハッシュに含む。

参照する確定足はFeedClosedの受理済み列だけ。SIGNALより後に公開される同時刻pivotや、バックログの後続足を先取りしない。描画コードから判定は変更しない。

## 固定した4月3日例

2024-04-03 07:05のXAUUSD+買い例を保存値で再現する。①は2276.72→2287.99、以前のH1/M15高値2288.35。帯は2287.7865〜2288.9135。予定entry2286.14、SL2282.83、最終TP2290.12、最新既知終値2285.10。この関係は本ルールのBLOCKEDに該当する。SHORT対称例も検証する。

これは保存例の条件判定であり、この変更版でその日の全データを再バックテストして約定比較した結果ではない。

## 検証の範囲

最終結果は **PASS: ネイティブ1,470項目・CSV別監査67項目、失敗0**。EAとハーネスはともに0 errors / 0 warnings。原版EA・共有モジュール等の12ファイル、往復計算モジュールは変更前ハッシュと一致した。プリセット4件は全42入力を含む。

見送りOFFは12候補すべてが従来のORDER_DISABLEDに進み、ONは4件をPRIOR_LEVEL_RETESTで終了、8件を許可した。両時間足とLONG/SHORTを含む合成fixtureである。注文ON試験は事前に阻害帯を確認した4件だけを処理し、ORDER/FILL/保有/待機注文はゼロ。ON/OFFで予定ENTRY・SL・TPは同一。6描画オブジェクト、2線の無効ray、判断時刻から下位足12本分の帯をMT5上で読み戻した。

今回は機能と因果性の確認。年間成績、利益改善、実ティックの約定精度、未使用期間での有効性は未検証。

全履歴の既知高安を参照するため、古く消化された水準が候補に残ることがある。「未突破」は最新既知確定終値が帯外縁を越えていないという意味であり、過去の全突破・消化履歴は分類しない。起動前のsetup再生はせず、起動後に確定するスイングから前向きに蓄積する。チャートの最終外観はユーザーのビジュアルテスターで照合する。
