## EAが実際に認識した入口

16時台の確定M5高安は、15:55安値109.419 →16:05高値109.537 →16:20安値109.453 →16:30高値109.566。安値・高値の切上げを16:45までに認識し、16:45～16:50足の終値109.439が押し安値109.453を下回った。実行価格109.438で売り約定した。

これを朝の第1・第2波からの初動として説明することはできない。現実装では、W1固定後もW2開始以後の最新2高値・2安値を繰り返し探索し、下位構造が失われても候補自体は維持する。その結果、後発の別の小さな逆構造を古い上位波に結び付ける。

## 目視とのズレと修正の原則

同じ問題を [5月12日の売り](../usdjpy_20160512_short_review/README.md) でも確認した。これは1分前倒しや抵抗除外だけで解決する問題ではなく、波の所属と候補終了を扱う設計の不足である。

- 下位足の逆調整が、どの第2波に属するかを保持する。
- 初回の進行を逃した候補を、後発の別の転換へ再利用しない。
- 上位第3波開始の観測と、その候補の終了を区別して明示する。
- 逆トレンド否定の初動と、下位足1→2形成後の第3波を別に扱う。

具体的な終了境界は動画で確定したルールではなく、ユーザーと照合する機械化仮定になる。時間制限や距離制限を恣意的に追加せず、まず各画像の波の区切りを合わせる。現時点で売買ロジックは修正していない。

## 確定待ちの制約

09:35の高値は後から認定したW2位置。現在のW1確定認識は09:45なので、09:35に遡って売れるとは扱わない。現在のガードでは最速でも09:45開始のM5足が閉じる09:50以降であり、他の条件がそこで揃うかは別途確認が必要。

この候補には11:55のTRENDLINE診断もあるが、価格109.552はすでに元のW1安値より低い。PIVOTからTRENDLINEへの変更だけでも初動の認識差は解消しない。
