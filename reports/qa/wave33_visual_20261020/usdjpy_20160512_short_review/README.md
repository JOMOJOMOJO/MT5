## 目視で確認すべき認識差

候補発生16:45から売り01:55まで9時間10分、W2高値18:35からは7時間20分空いている。EAはW1終点を固定した後、上位足96本のタイムアウトや始点破壊まで同じ候補を保持し、その間に現れる新しい下位HH/HLを探索する。

このため、画像の長い横ばいの後にできた小さな上昇の否定を、前日の大きなW1/W2に結び付けた。第1波安値108.436は売り時点ですでに下回っている。現行コードには「既に第3波が始まった」「長いレンジに移行した」「W2高値から長時間経過した」ことだけで候補を閉じる条件はない。
