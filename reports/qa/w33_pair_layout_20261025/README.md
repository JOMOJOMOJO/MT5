# Wave33 v1.84: 接続逆①の両側見送り・ラベル整理

## 変更と使い方

テスターで `dev\\mql\\Experts\\Wave33ChopDiagnostic.ex5` を選び直して再開始する。新設定は次の2つで、どちらも初期値ON。

| 入力 | 初期値 | 動作 |
|---|---|---|
| `InpSkipBothConnectedWave1` | true | 接続する逆①の両方が未発注なら、古い側・新しい側を両方終了 |
| `InpReadableLabels` | true | 文字を短縮・間隔配置し、根拠位置へ有限の引出線を表示 |

両側見送りONは `InpCancelConnectedOpposite` より優先する。両側OFF・従来フラグONなら古い側だけ取消、両方OFFなら接続による取消なし。上位足高安帯の見送りは従来どおり `InpSkipPriorLevelRetest=false` が初期値であり、別の機能。

両側見送りは、旧①の**確定終点の日時・価格**を新逆①が起点にする場合。価格差の許容は半ポイントで、同じ銘柄・時間足の組だけを対象とする。逆方向の①が近くに見えるだけでは適用しない。見送り理由は両IDに `CONNECTED_OPPOSITE_W1_BOTH`、分類EXCLUSION。新候補の追跡・発注も止め、両方向枠を解放する。

注文送信中・約定済みの取引は遡って取消しない。その場合は逆①の観測を継続し、「約定後に逆①が確定したら、推定コスト込みでプラスになった時点で決済」を保持する。

## 表示

①・②、ENTRY、SL/TP、見送り、往復、高安帯などの文字を短縮して間隔配置する。同じ候補は共通の短い `#番号` で照合できる。元の高安の時間足・位置日時・価格は表示に残し、詳細な理由・知り得た時刻・元の全文はツールチップとCSVに保持する。

移動するのは文字だけ。高安・判定線・売買価格は変えない。点線の引出線が、実際の時刻・価格と文字の対応を示す。ズーム・横移動・画面サイズ変更では元の座標から再配置し、ずれを累積させない。固定パネルは増やさない。

勝ち・負け・見送りの記録や過去のアンカーは削除しない。画面が全ラベルを置けないほど極端に密集した場合は、履歴を隠す代わりに一部重なる限界がある。その場合は拡大・表示区間の短縮が必要。
