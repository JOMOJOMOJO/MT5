# Wave33 v1.50：上位足の確定終値が61.8%を超えた候補を除外

ユーザー承認の条件を実装し、RR1・構造SL・認識方式2・W1最低余地0.25Rは固定して検証した。ヒゲだけの超過では除外せず、**上位足の確定終値**が深い側へ境界を超えた未成立候補を終了する。

- A=M15×M5はM15終値、B=M5×M1はM5終値を使用。
- 新入力`InpRejectDeepFibClose=true`。旧ヒゲ除外`InpRejectDeepFib=false`は維持。
- LONGは固定Fib61.8%価格より下、SHORTは上で除外。61.8%ちょうどは許容する。数値演算の1ulp相当の等号誤差だけを吸収し、価格ポイント単位の猶予は追加しない。
- W1確定待ち中の上位足を後から分類する場合も、元足/終値確定/判断可能時刻を分ける。シグナル・保有後へ遡って適用しない。
- 同時刻の確定足はH1→M15→M5→M1の順。欠落後の複数足処理にも共通ソートを適用した。
- `FIB_CLOSE_TOO_DEEP`、元終値、押し率、3時刻をCSVに記録。別`upper_bars.csv`に受理した全上位OHLCと既知時刻を残し、違反足だけの抜粋にしない。

**Aは総損失が減ったが、取引数が半減し、平均Rは悪化した。今回の条件だけで収益改善したとは認定しない。** Bは平均Rが上がったものの短い期間・12決済で、合計Rはわずかに減っている。利益で設定値を探索せず、この固定比較で止める。

Aで消えた21決済は勝ち9件・負け12件で、新しい約定の追加は0件。狙った負け1件だけを除外した変更ではない。

RはEAがprofit・commission・swap・feeを含めて記録した最終EXITのRを各候補1回だけ集計した補助値。未決済をゼロ損益へ置換していない。口座通貨PFや資本推移と同一視しない。候補を早く終了したことで後の成立が変わる場合も、全候補の表で追う。
