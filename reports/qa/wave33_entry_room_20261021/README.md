# Wave33 v1.40：第1波付近の遅い入口と抵抗の出所

ユーザーが示した2018年9月6日・17日・24日の遅い買い3件は、同じ候補・固定W1を再現した上で、**第1波終点までの余地不足として発注を見送り**になった。良い例の4月26日買い、9月5日買い・売りは元と同じ時刻を維持した。[固定10事例の4設定比較](final_case_comparison/README.md)

この判定は動画一致・利益改善の認定ではない。ユーザー画像を用いた実装修正の回帰確認であり、0.25Rは明示した初期仮定である。[事前固定した比較計画](../../../knowledge/experiments/2026-10-21-wave33-entry-room-plan.md)

## 変更

- `InpMinWave1RoomR=0.25`：実行可能なAsk/Bidと丸めた構造SLを使い、進行方向の固定W1終点までの距離をSL幅で割る。最低値未満は`WAVE1_ROOM_TOO_SMALL`。W1を既に超える入口は負の値になる。0で無効。SLを狭めたりTPを短縮する変更はしていない。
- `InpLowerRecognition=2`：確定済みpivotを同側の最も極端な点へ整理した完成逆構造を優先。短い調整には、確定W2極値の後の**最初の確定した反応pivot**の新規終値突破も別経路で認める。`SIMPLE_REACTION_BREAK`は厳密な下位1→2→3の成立とは区別する。mode0は旧比較、mode1は整理した完成逆構造のみ。
- 余地不足で発注しなかった候補をその時刻で終了し、次の独立した上位足突破を待つ。古いシグナルを再利用しない。途中版で拒否候補が同方向枠を占有し、良い9月5日買いを阻害したため修正した。
- 青は「①高値／安値まで xR」。紫は別の既知水準を`R+識別子`、時間足、高値／安値、元日時と共に表示。同じ識別子を元の高安にも置く。ツールチップに`source / known / adopted`の3日時を保存する。
- 過去の安値が買いの上にある等の逆の役割は「参考」と表示する。紫候補は全確定M5/M15/H1高安とW1からの最寄り水準で、重要度・古さ・突破済みの選別は追加していない。既存の`DISPLAY_ONLY`を維持する。**紫線がENTRY付近にあること自体を売買条件にしていない。**
- 固定パネルOFF、線は有限。余地拒否は緑ENTRYを描かず、赤い見送り理由を残す。青・紫・見送りが重なる事例は文字だけを移動し、元価格を点と補助線で示す。取引判定の価格は変えない。
