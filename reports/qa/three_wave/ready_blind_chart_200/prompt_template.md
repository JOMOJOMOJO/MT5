# 固定判定プロンプト

以下を新規チャットへそのまま貼り、画像を添付してください。候補の管理対応表や研究レポートは添付しないでください。最初はraw画像のみを渡します。annotated版を比較するときは別の新規チャットを使い、もう片方の画像や判定結果を渡さないでください。

---

添付した各チャートについて、**右端時点からLONG方向への継続可能性を、画像だけから評価してください。**

画像は1候補につき4パネルです。左上M1、右上M5、左下M15、右下H1です。表示本数はそれぞれ120、96、64、48本です。右端は各パネル共通の判定境界です。

表示しているのは判定時点で閉じていたローソクだけです。形成途中の足は表示していません。横軸は確定足の順序であり、取引休止等の空白時間を含む実時間間隔ではありません。H1等では最後の確定足から判定時点までの途中の動きは描かれていません。

縦軸は判定時の基準価格からの相対pipsです。各パネルの縦軸は表示ローソクの高安に合わせているため、見かけの角度だけを異なるパネル間で直接比較しないでください。

外部情報の検索、日付・銘柄の特定、過去に見た類似画像の結果の推測はせず、見えている形状だけを根拠にしてください。良い候補が一定数あると仮定せず、A/B/Cを均等に割り当てないでください。

以下の7項目を評価してください。

- overall_grade：A / B / C。AはLONG継続を支持する形状が比較的明確、Bは支持と反対の材料が混在、Cは支持が弱い、または反対材料が目立つ場合。
- continuation_probability：0〜100。右端からLONG方向へ継続しそうかという主観的評価。指定された値幅や保有時間への到達確率ではありません。
- wave1_quality：0〜100。見えている直近の上昇局面の勢い・滑らかさ・持続性。
- wave2_quality：0〜100。その上昇後の押しの整い方・崩れにくさ。
- selling_pressure_decay：0〜100。直近で売りの勢いが弱まっているか。
- higher_tf_alignment：0〜100。M15/H1の形状がM1/M5のLONG継続を支持しているか。
- comment：画像を根拠とする短い理由を1〜3文。

明確な波が見えない場合も、形を無理に当てはめず評価に反映し、commentに不明瞭な点を記してください。画像が読めず判定できない場合は、その画像について推測した数値を出さず、blind_idと判定不能の理由を返してください。

各画像上部のランダムIDをblind_idとして、次の形式のJSON配列だけを返してください。blind_id以外に日付や候補番号を推測して追加しないでください。

```json
[
  {
    "blind_id": "画像上部のID",
    "overall_grade": "AまたはBまたはC",
    "continuation_probability": 0,
    "wave1_quality": 0,
    "wave2_quality": 0,
    "selling_pressure_decay": 0,
    "higher_tf_alignment": 0,
    "comment": "画像を根拠にした1〜3文の理由"
  }
]
```

例の0は形式を示す仮置き値です。実際には各画像について独立に評価してください。
