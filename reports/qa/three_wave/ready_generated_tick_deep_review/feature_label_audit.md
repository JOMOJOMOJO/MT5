## 1. 勝敗ラベルとR損益は同じ目的変数ではない

CollectorはSLを最初の到達Bidで決済し、TPは設定TPに損益を固定している（`USDJPY_Ready2024MLCollector.mq5:74-78`）。ギャップがあれば負けは−1Rを超える。このモデルは保守的だが、`TP=1 / SL=0` の二値分類だけでは負け幅の差を学習目標に含めていない。

| 項目 | 学習対象2083件 |
| --- | ---: |
| −1Rを下回る負け | 574 |
| −1.2Rを下回る負け | 48 |
| −2Rを下回る負け | 10 |
| 最悪R | −6.058824 |
| SLを−1Rに固定した名目バリア平均R | −0.142362 |
| 保存された約定モデルの平均R | −0.168585 |
| SL超過損失の合計 | −54.621330R |

−1R未満574件には小さいtick超過も含む。これをすべて大ギャップと呼ばない。TPのtick丸め後の設定RRは1.1875〜1.214286で、厳密に全件1.2ではない。勝敗AUC向上をそのまま期待値向上と扱わず、元の損益と名目バリア損益の両方を診断すべき。

## 3. トレンドラインとEntry geometry

`build_ready_2024_ml_dataset.py:84-100` のM15/H1線は「最新2つの確定high同士／low同士を結び、Entry時刻まで延長した直線」。3点目の接触、途中の線突破、線の有効期限を検証していない。未来情報の問題ではないが、有効な支持抵抗トレンドラインが検出済みという意味ではない。

既存117特徴には `risk/ATR`、M1 HL確定からEntryまでの待ち時間、EntryのM1 Wave1 Highからの上乗せ幅は直接含まれていない。保存済みのEntry時点情報から計算可能。候補2083件の中央値はrisk/M1 ATR=5.9597、Entry−M1 Wave1 High=0.1955R、HL確定後待ち=1分、CHoCH後待ち=12分。これらの追加を採用するときも固定した少数定義で一度だけ比較し、Entryルール自体は変えない。

## 最大3つの診断軸

1. **構造のみ vs 構造＋時刻・spread**。同じ年次前進分割・候補で比較し、モデルの寄与が生成tickの摩擦仕様に依存するか確認。
2. **勝敗予測 vs 損益の大きさ**。原ラベルは維持し、約定モデルRと名目バリアRを併記。深いSL超過の寄与を別集計し、勝率予測だけで正期待値を主張しない。
3. **少数のM1 Entry geometry**。上記3〜4個の時点既知特徴だけを事前固定で追加し、遅い／高いEntryとSL幅の関係を診断。新しいpivotやEntry条件、閾値の反復探索は行わない。
