# M5初動の時系列修正・高安表示改善

## 変更したルール

EA v1.01 / Shared indicator v1.07。M5 Wave1高値を固定し、その高値を**M1確定足の終値**が初めて厳密に上抜いた時点で、M1のREADYが完成していなければ親セットアップを終了する。

- M1 CHoCH前、HL待ち、HL確定後のトリガー待ち、M1無効化・再探索中のすべてに適用。
- 最初のM5突破とM1 READYが同一確定足なら採用。足内の先後は推定しない。
- ヒゲだけの突破・同値は従来の終値ブレイク定義を維持して終了条件にしない。
- 一度取り逃した親波は価格が戻っても再利用しない。
- READY発生後の将来データで過去の候補を削除しない。
- 新規シグナルは新M1足で1回。実際の成行約定は次のティックであり、シグナル終値と同価格とは限らない。

SMA/RSI/ATR、追加時間足、スプレッド・時間帯フィルターは追加していない。ピボット2/2、リスク1%、RR1.2、SLバッファ10 points、15分クールタイムも維持。

## 取引数が少ない理由

4月の各イベントを経験した親セットアップ数（期間内のイベントを親IDで重複除外。再試行・月跨ぎがあるため単純な排他的分類ではない）：

| 段階 | 修正後 |
|---|---:|
| M5 CHoCH | 92 |
| M5 Wave1高値確定 | 88 |
| M1 CHoCH | 40 |
| M1 Wave1高値確定 | 29 |
| M1 HL確定 | 20 |
| READY・発注 | 14 |

M5先行突破による終了45構造、M5起点割れ25構造。これらは途中のM1イベントと重複する。今回は候補14件すべて発注されており、発注拒否やクールタイムが少取引の主因ではない。

現在のM1下降判定は高値2つ・安値2つの切り下げを必要とし、さらにCHoCH後の高値とHLの確定を待つ。2/2ピボットはM1で右2本、M5で右2本の確定が必要。単に押して上昇した形すべてを採用する定義ではない。この定義と目視で考えるチャンスの差を検証する余地はあるが、今回、感度や下降条件を緩めて件数を増やす変更は行っていない。

## チャート表示

- M5高値: 大きいオレンジ下矢印、安値: 大きい水色上矢印。親波は太いオレンジ線。
- M1高値: 小さい赤下矢印、安値: 小さい青上矢印。内部波は細い灰色線。
- 同じ種類のピボットが連続した部分は無理に線を結ばない。未確定の最終波も描かない。
- `InpShowHigherPivots` / 新設 `InpShowLowerPivots` で個別切替。新設 `InpShowPivotLabels=true` でTFとH/Lの文字を表示。標準は文字なしで重なりを軽減。
- 矢印のツールチップにTF、H/L、価格、ピボット時刻、確定時刻。価格座標は実価格。
- 緑の `LONG CANDIDATE` は構造上の候補。EAの実約定は `Entry` と注文番号、SL/TPで確認。インジケーター単体では売買・口座制約の確認をしない。
- M1 HLをFib圏外という理由で赤く表示するのをやめた。Fibは売買条件に追加していない。
- データ未準備時に既存描画を消さず、2秒タイマーで再取得。インジケーターごとの固有オブジェクト名で複数装着時の衝突を防ぐ。
- 表示上限はM5直近80ピボット、M1直近120ピボット。セットアップ描画数は既存入力。これらは売買件数上限ではない。

### 読み込みエラーと入れ替え手順

ユーザーの `[538]` は別製品 `Market/Linear Regression Candles MT5.ex5` のエラー。今回のEA/Sharedはその製品に依存しない。MQL5公式サイトの[当事者のエラー報告](https://www.mql5.com/en/forum/464921)では538がinvalid licenseとして記録されているが、今回の端末固有の認証原因までは断定できない。Market製品を使う場合はMT5のCommunityログイン・購入済み一覧を確認し、同じMQL5アカウントのMarketから正規に再インストールする。ライセンスやMarketファイルは変更していない。

実際のログでは17:10頃まで原版 `v1.05_InvalidationReset` がXAUUSD+/M1で動作していた。

1. ナビゲーターを更新し、チャートの原版v1.05を外す。
2. `Indicators/MultiTF_3WaveIn3Wave_Visualizer_Shared` をM1チャートへ追加。
3. 名前が `3Wave-in-3Wave Shared v1.07` であることを確認。上下ピボット表示をtrueにする。
4. 緑の候補を実エントリーと区別する。EA検証はUSDJPY/M1で行う。インジケーターはXAUUSD+でも描画できるが、EAはUSDJPY専用。

稼働チャートへの自動装着・EA有効化は行っていない。原版v1.05と旧Fib50 EAは保存し、新Sharedと3Wave EAを更新する。
