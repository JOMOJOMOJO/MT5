## 入れなかった理由

EAはショート準備に「M5の高値・安値がともに切り上がる、交互の4確定スイング」を要求する。03:20高値110.220が03:35に確定しても、直近安値は02:45の110.115 → 03:00の110.094と切り下がっている。その後も03:35安値110.088へ下がり、必要な上昇調整を認定していない。

早い段階では00:30高値110.168 → 01:05高値110.174、00:30安値110.117 → 01:00安値110.138があるが、00:30が同一足の高値・安値なので、先後不明として交互順序の条件を満たさない。その後01:05と02:05の高値は同値110.174で、厳密な高値更新にもならない。

この候補のLOWER_STRUCTURE_CONFIRMED・REJECTED・LOSTはいずれも0件。新しいW2所属チェックが有効な売りを拒否したケースではなく、その前の下位構造が未成立だった。該当CounterPivots関数はv1.20バックアップと同一。[比較記録](recognition_comparison.json)

したがって前回の変更は「未成立だった古い候補を04:15で終わらせた」部分に作用している。「初動を逃した」は終了理由であり、売り条件未成立の原因を説明する表示になっていない。単にPIVOTをTRENDLINEへ替えても、現在の共通前提である下位構造確認には到達しない。

画像2は `W33_USDJPY_15_5_LONG_1524763800_112` と一致。2018.04.26 20:30に下位構造を確認し、20:35に109.268で買い約定。W2安値109.190、SL109.178、TP109.358。ユーザーが良いと評価した成立例として保持する。
