## 1枚目：8月27日の買い候補

候補07:30、W1は05:45安値110.932 → 08:00高値111.131（既知08:45）。W2開始は08:15、安値09:00の111.010。最初の下位高値は09:10の111.065で、次の09:55高値111.112が既知になる10:10までは1点だけである。

その間、安値は09:00の111.010 → 09:25の111.020へ切り上がり、後続の高値・安値も上がる。現行EAが買い準備に要求する、完成したM5下降LH/LLは一度も作れない。11:00に10:55足終値111.151がW1高値を上回り、候補終了。

単純な押しから上昇する形を、下位逆トレンドの高安2組を要求する条件が拾わない例。所属不一致や交互順序の拒否ではない。[候補イベント](image1_aug27_long_events.csv)、[既知pivot](image1_aug27_long_pivots.csv)
