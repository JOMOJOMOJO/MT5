# 画像3事例：旧設定の再現と候補寿命の修正確認

時刻は元データのブローカー時刻。セットアップ番号を使わず、銘柄・方向・候補時刻・第1波始点で照合する。
旧挙動を再現できない事例は、修正済みとは判定しない。成績・動画との完全一致を評価する比較ではない。
