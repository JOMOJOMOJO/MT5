## 判定と確定時刻

取得配列は古い足が0番、最後が形成中の足。候補 `i` の左右でHighがすべて厳密に小さければ高値、Lowがすべて厳密に大きければ安値。同値は不採用。左右の本数はそれぞれ独立入力。

候補は `i + right < count - 1` の場合だけ処理する。`bar_time = rates[i].time`、`confirmed_time = rates[i + right + 1].time`。つまり右確認足の次の実在足が始まった時刻に利用可能になる。無配信期間・週末は次の実在足まで保守的に遅れる。

確定記録は追記のみ。一度処理した候補時刻以前は再判定せず、価格・時刻・既存の線端点を置換しない。履歴修正や `prev_calculated=0` でも同じインスタンス内の記録を保持し、バッファーは記録から再投影する。表示切替や入力変更による再初期化は別の計算セッションとなる。

矢印と線は表示用オブジェクト。M5はM5足の始値時刻へ配置し、その5分間に含まれるM1足の実際の極値時刻へ移さない。高安同時成立は両方の点を残すが、前後の線を接続しない。同種連続も点を残して、その区間の線を省く。

## バッファー契約

すべて候補足のM1時刻に置く。非該当は `EMPTY_VALUE`。表示をOFFにしても値は提供する。

| 番号 | 内容（デフォルト時間足） |
|---|---|
| 0 | M5確定高値の実価格 |
| 1 | M5確定安値の実価格 |
| 2 | M1確定高値の実価格 |
| 3 | M1確定安値の実価格 |
| 4 | Buffer 0の確定時刻（datetimeをdoubleで格納） |
| 5 | Buffer 1の確定時刻 |
| 6 | Buffer 2の確定時刻 |
| 7 | Buffer 3の確定時刻 |

入力時間足を変更しても0/1はHigher、2/3はLower。0〜3はデータウィンドウにも表示。4〜7は `CopyBuffer` 向け。

**過去の候補位置への遡及表示であり、その足の時点で知っていたシグナルではない。** 将来EAで過去データを参照する場合は、対応する確定時刻が評価時刻以下であることが必須。今回は売買判定を実装していない。

3. 初期入力のM1/M5、左右2本で赤い下矢印・青い上矢印、太いオレンジ下矢印・水色上矢印を確認する。細線が太線の波の内側を往復する様子を見る。
4. 矢印へマウスを重ねて、時間足・種類・価格・pivot bar time・confirmed timeを確認。左上にも件数と最新高安の両時刻が表示される。
5. M5チャートと比較し、M5矢印の時刻が候補M5足の始値時刻に一致することを確認する。左右2本なら候補時刻から通常15分後に確定する。
6. 新しい足ができる前後で既存矢印・線が移動しないことを確認。候補から右側2本が閉じるまでは追加されない。
7. 4つの表示スイッチと左右本数を変更して表示・感度を確認する。入力変更は再初期化されるため、旧設定と同じ点を保存する操作ではない。
8. インジケーターを削除し、別に描いた線が残ることを確認する。

別端末へ配布するときはEX5のみでも動作する。ソースから再コンパイルする場合は上記の相対位置にヘッダーも配置する。

## 再検証

検証スクリプトは専用の合成カスタム銘柄 `SSV_QA` の履歴を作り直す。通常銘柄の履歴は変更しない。独立したテスト端末で使用する。

1. 検証スクリプトをコンパイルし `MQL5/Scripts/`、インジケーターEX5を `MQL5/Indicators/` に配置する。
2. スクリプトを一度M1チャート上で実行して専用銘柄を作成する。
3. `SSV_QA` のM1チャートで同スクリプトを再実行する。iCustomのオブジェクト描画先を一致させるため、呼び出し元チャートも対象銘柄と一致させる。
4. Expertsログの `SWING_STRUCTURE_RESULT checks=29 failures=0` と `MQL5/Files/swing_structure_qa.png` を確認する。

この作業では既存 `scripts/compile.ps1` のMetaEditor選定を確認した上で直接コンパイルした。同スクリプトはExperts配下の生成物を他端末へ自動コピーするため、Indicatorsの今回の配置先に合わない。既存スクリプト自体は変更していない。

初回の独立端末は標準銘柄キャッシュが破棄され、スクリプト開始を待機した。現在形式の銘柄定義だけをログアウト用キャッシュへ読み込み直して解消。認証情報はコピーせず口座も作成していない。初回テストでM5履歴の非同期準備が見つかり、インジケーターに1秒タイマーの再試行を追加した。テスト自体もM5バッファーの準備を待ち、前回追加した合成バーを消してから再実行するよう修正した。

## 制限

- 適用先はM1限定。入力は明示的な時間足、Higher > Lower、左右各1〜10000本。
- 初回は各時間足直近5000本まで（`InpInitialHistoryBars`）。初期取得できた履歴より古い領域を後から追加検出しない。稼働中の新規確定点は削除しないため、長期間ではメモリとオブジェクト数が増える。
- 入力変更・削除/再適用・再起動後は当時の履歴から再計算する。永続保存はなく、ブローカーによる履歴訂正後の再起動で同じ結果になる保証はない。
- 元のM1足がチャート履歴に存在しない場合、その位置のバッファーを他時刻に代入しない。オブジェクトの元時刻と記録は保持する。
- 判定済み候補を遡及再判定しないため、後から修正された履歴との完全一致より稼働中の確定点保持を優先する。
- 矢印の重なりやチャート上下端での見切れはチャートの倍率・余白で調整可能。複数インスタンスのデバッグ表示は `InpDebugTopPixels` でずらす。
- M1/M5の同時表示だけであり、各M1波へのM5親波ID付与、A/B/C、C以降の内部波、エントリー候補は未実装。

実装時に参照した標準API仕様：[CopyRates](https://www.mql5.com/en/docs/series/copyrates)、[SetIndexBuffer](https://www.mql5.com/en/docs/customind/setindexbuffer)、[MT5起動設定](https://www.metatrader5.com/en/terminal/help/start_advanced/start)。
