# quality12b 固定条件の再検証

**検証終了後の最新判断：[summary.md](summary.md)。11実行終了後に品質ゲートの不備を修正したため、旧COMPLETEDを全データ品質合格とは扱わないでください。現データでの再実行はtrainの生成tick補完検出で停止する設計です。**

`RUN_ALL.cmd`で開始します。初めに過去2期間の再現を確認し、合格時だけ2018〜2025各年と2026年4〜9月へ進みます。合計11回。重複期間を合算して全成績と扱わないでください。

- USDJPY / M15 / リアルティック / 最適化なし。
- 過去MT5レポートの全163inputを固定。SL22pips、TP1.5R、リスク0.65%、その他の管理条件も元の値です。
- EAソースは現在の原本をバイト一致で保存。旧EX5と同一とはまだ証明されていないため再現確認が先です。
- 独立MT5をLOCALAPPDATA/CodexMT5Quality12bに毎回新規作成。既存MT5を停止しません。
- VantageTradingLtd-Liveの既存接続設定を独立MT5へローカルコピー。接続・履歴取得が発生します。通常チャートの自動売買は無効、EAはテスター内だけで実行します。
- 口座番号・認証情報はレポジトリの実行設定に保存しません。稼働用INIは独立MT5側のみです。
- ログのファイル名3項目だけ実行ごとの固有名に変更。本番EA・元preset・Sharedは変更しません。
- リアルティック履歴が不足した結果を、生成tickへ自動変更して続行しません。
- 各回上限2時間。コンパイル異常、原本との再現不一致、レポート監査不合格では停止し、理由を保存します。
- 再現条件（初回停止の原因確認後に更新）：各取引のEntry/Exit時刻・価格・ロット・SL/TP・決済理由・売買損益・手数料、入力値、足数/ティック数が一致すること。スワップだけの差は取引ごとに純益差と一致することを確認し、別記して続行します。実際の損益からスワップ差を消しません。
- 初版は純益差0.02 USD以内という総額比較でした。初回の純益差−6.89 USDは9取引のスワップ差だけで、60取引の売買内容は一致しました。初版FAILED記録を保存し、差額監査を追加しています。
- 全11期間と入力値は固定のまま、再現2期間の後は2026年4〜9月、2025年、2024年、以後過去年へ進みます。古い履歴の不足で直近の検証まで止まるのを避ける順序です。異常時停止の方針は維持します。
- 2026年4〜9月も未使用性を未確認のためOOSと呼びません。

## 出力

`runs/<実行ID>/status.json`：RUNNING / COMPLETED / FAILEDと理由。
`summary.csv`：期間別の件数・純益・PF。
各期間フォルダ：report.htm、inputs.set、trades.csv、metrics.json、匿名化したjournals。
`metrics.json`に最大利益取引、週末持越し、TP超過約定、最大利益取引を単純除外した感応度を記録します。単純除外は再バックテストではありません。

## PowerShellで確認だけ

リポジトリで `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/run-quality12b-revalidation.ps1`。
`-Execute`がなければ起動せずチェックだけです。`-Stage Reproduce -Execute`で最初の2期間だけ実行できます。
手動で途中終了してrunner.lockが残った場合、該当実行のPowerShell/MT5が停止していることを確認してから、そのlockだけを削除してください。

ローカル検証：PowerShell構文、凍結ハッシュ、元レポート再集計、スワップ差のみの受理、価格やパラメータ変更の拒否、実tick比率と該当journalの補完検出を含む16テストを確認。最新の結果と品質訂正はsummary.mdに記録しました。
