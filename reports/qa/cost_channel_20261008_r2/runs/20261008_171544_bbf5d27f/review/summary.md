# 固定日足チャネル研究：最終確認

## 結論

修正版3本は完了し実行監査に合格。ただし今回の固定日足戦略は利益・頻度の両方で目標未達。本番採用せず、この設定の研究サイクルは中止とする。利益を見て銘柄や閾値を選び直さない。

対象はUSDJPY / EURUSD / GBPUSD / AUDUSD / XAUUSD。日足20本チャネル終値突破、初期SL=日足ATR14×2、固定TPなし、反対側10本チャネル終値突破で決済。初期資金10,000 USD、リスク上限0.25%/取引。月20件を目指す従来のM5 EAとは別研究。

2023–2024と2025–2026年9月は各10,000 USDから独立開始。合計は取引損益の和であり、連続運用の複利収益率ではない。QAの7取引は重複集計していない。PFはswap等を含む取引純損益から再計算。

全96取引の平均約定価格R=-0.2334。これは価格差/初期SL幅であり、swapを含む口座通貨の平均Rではない。純損益/件=-4.44 USD。swap合計=-52.62 USD、手数料・feeは記録上0。

## 頻度と見送り

45か月平均2.13件/月、最少0、最多6件。0取引の月=5、20件以上の月=0。平均保有27.3日、中央値18.0日。

非保有時に記録された銘柄・シグナル日足の重複除去後389件：実行96、ロット/リスク制限167、最大保有数またはポートフォリオ/USD方向集中制限126。

この戦略にはspread上限フィルターはない。休場再試行を候補数へ重複算入していない。保有中は新規シグナルを記録しないため、上記は全無制約shadow候補ではない。制限を外した場合は保有経路が変わるので、この件数から無制約成績を推定できない。

XAUUSDは全149候補がVOLUME_OR_RISKで見送り、約定0。従ってゴールドの売買成績は未評価。コード上、この理由は刻み切り下げ後の最小ロット未満または予定損失の予算超過を指す。現行ログは両理由を分離していないので、全件を最小ロットだけが原因と断定しない。

成立注文の予定リスクはEquityの0.125〜0.246%、平均0.181%。0.25%は上限で、ロット刻み以下へ切り下げるため常に0.25%にはならない。

USDJPYのプラスも20件の小標本で、最大利益1件を除くと負。この結果からUSDJPYだけ選んで採用する根拠にはしない。銘柄別は同時運用の内訳であり、独立した銘柄別テストではない。トレンド追随では少数の大きな利益への依存自体はあり得るため、最大利益除外だけを棄却理由にはしていない。

- buy: 52件、純損益-219.24 USD、PF 0.568。
- sell: 44件、純損益-206.58 USD、PF 0.538。

年別でも2023/2024/2025/2026は全体純損益が負。年はEntry年で分類し、期間末強制決済を含む。最大利益の除外は集中度診断だけで、外れ値として本集計から削除していない。

## 実行の正しさと限界

- コンパイル0 errors / 0 warnings。3runともnativeレポートとdeal/損益/件数/設定一致。5銘柄の期間先頭から末尾までの評価を確認。
- 本比較2本の休場拒否は44+28=72回で、72回とも再開を記録。QAの8回も再開。未処理の休場再試行なし。
- 初版の失敗run・途中レポートを採用していない。完了済みM5コスト分析4本はhash固定で再利用。
- 本比較は生成tick混在（MIXED_TICKS）。既知期間なのでOOSではなく、実運用の保証でもない。
- 日足の同期quote両端が揃った取引は35/96件だけ。残りも実損益には含め、コスト内訳のみ欠損とする。元summaryのmid/spread平均はこの部分集合、fill平均は全件なので横引き算しない。
- 同じ35件に限定するとmid平均-0.1586R − spread平均0.0393R = fill平均-0.1979R。欠損群へこの比率を外挿しない。
- M5コスト分析は447/447件の同期quoteが揃う。LONGのmid寄与+0.077Rにspread負担0.070R、SHORTはmid寄与自体−0.068R。決済時刻固定の帰属であり無コスト再シミュレーションではない。
- 本番EA・Shared・既存売買パラメータは変更していない。今回追加したのは読取り専用集計と記録のみ。

## 次の判断

今回の固定日足チャネルを、勝てる代替手法や月20回の解決策として採用しない。リスク制限を緩める、結果が良い銘柄だけ残す、退出本数を探索する追加テストは開始しない。引き継ぐのは注文監査・コスト分解・候補から実行までの件数記録。次の仮説は別途定義してから研究する。
