# Wave33 v1.61：RR入力を明示

既存の `InpRewardR` は既にLONG/SHORT・両時間足共通でTP計算に使われていた。入力キーを維持し、MT5での表示を **リスクリワード比（SL=1に対するTP倍率）** とした。1.0=1:1、1.5=1:1.5、2.0=1:2。既定1.0、指定は0より大きい値。

今回の変更は入力コメント、EA版、ログの版情報のみ。主EA全文を旧ソースから3箇所だけ置換した結果と一致し、全共有ヘッダーのハッシュも不変。[確認結果](verification.json)。逆①確定後のプラス決済、SL、ロット、エントリーの実行コードは変更していない。

隔離MetaEditorで主EAをコンパイルし0 errors / 0 warnings。[コンパイルログ](compile.log)、[ビルド](build.json)、[配布ハッシュ](deployment.json)。通常の端末は中断せず、EX5と新しいA/B設定を配置した。共通コンパイルスクリプトの全端末同期を避け、今回のEAだけを対象にした。

表示・版情報だけの変更なので追加バックテストは行わず、[v1.60の売買・決済検証](../w33opp/README.md)を維持する。RR値の最適化は行っていない。`CAP_TP` を選べば抵抗線までTPを短縮し、逆①利益決済ではTP前に終了するため、設定RRと実現Rは区別する。

更新後はテスターを停止してEAを選び直す。[A設定](../../presets/wave33-v161-A-M15-M5-orders.set) / [B設定](../../presets/wave33-v161-B-M5-M1-orders.set)。キー名を変えていないので旧SETのRR指定も引き継ぐ。[入力手順](../../../docs/validation/wave33-tester-orders.md)。
