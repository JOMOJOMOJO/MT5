# エントリー前の波形を確認するための固定データ

対象は v1.80 / XAUUSD+ / 2020 年の完結取引 440 件。EA・テスター・元の年間分析結果は変更していない。

## 分離したファイル

- `blind/packets.json`: 画像用の 60 事例。勝敗、損益、決済時刻、決済理由、エントリー後の足を含まない。
- `features_causal.csv`: 年間 440 件について、注文時点で計算できた特徴。勝敗・損益を含まない。
- `labels/label_key.csv`: 画像 ID と決済結果の対応。画像の評価を固定するまで開かない。
- `labels/features_all.csv`: 特徴と年間取引結果の対応。画像の評価を固定してから使う。
- `labels/selection_audit.json`: 選択対象数、固定割当、時系列内の選択インデックス。
- `manifest.json`: 入力・出力ハッシュ、カットオフ、利用可能数、固定した区分。

選択は、A/B・LONG/SHORT・勝敗ごとの固定割当で行った。各群を約定時刻と setup_id 順に並べ、`floor((i+0.5)*N/n)` の位置を選び、seed 20261023 で表示順を混ぜて V001〜V060 を付けた。利益・損失の大小では選ばない。勝敗を揃えた画像標本は、年間の勝率を推定するための標本ではない。

## 当時の情報だけを使う条件

各事例の `snapshot` は CSV の **ORDER 行そのもの**から、事前に固定した許可フィールドだけをコピーした。FILL や EXIT の行で更新していない。イベント順序は CSV ヘッダーを除いた 0 始まりのデータ行番号。

表示する確定スイングは `PIVOT_CONFIRMED` 原本から取得し、`event_sequence < ORDER sequence` かつ `known_at <= ORDER 時刻` を満たす。両者を要求するので、同じ時刻でも ORDER より後の行に記録されたスイングは入らない。

足 CSV は別ファイルで全体イベント順序がないため、`known_at <= ORDER 時刻` に加え、`closed_at <= 下位足トリガー足の終値時刻` で制限する。EA の FeedClosed は足の終値時刻順、同じ終値時刻は上位足から処理する。この追加条件により、ティック欠落後の一括処理で同じ known_at を持つ後続の足も除く。

①より前のジグザグは、スイングの `time < ①起点 time`、`known_at <= 上位足ブレイク足の始値時刻`、`sequence < WAVE1_BREAK sequence` を要求する。これは EA の上位足構造探索の knownBy に合わせた、ORDER 時点より厳しい固定範囲。

確定した同種の高値・安値が連続する区間では、その区間の極値を残して交互の列にする。同一の足に高値・安値が両方ある場合、先後関係を想像で付けない。両者に `ambiguous_same_time` を付け、交互列をそこでリセットする。その後に 8 点揃わなければ、その特徴は利用不能とする。生の表示用スイングの曖昧フラグも保持している。

タイムスタンプは元ログのブローカー／ソース時刻。UTC 対応は未確認。

## 固定した特徴の定義

| 特徴 | 計算 | 固定区分 |
|---|---|---|
| ①値幅 / 直前の波の大きさ | ①の起点〜終点値幅 / 直前の交互 8 点から作る 7 本の値幅中央値 | <1 / 1〜<2 / ≥2 |
| ①値幅 / 直前 TR14 | 起点より前に終了した 14 本の True Range の単純平均で割る。直前終値用に 15 本必要 | <2 / 2〜<4 / ≥4 |
| ①の終値効率 | 起点足〜終点足の `売買方向 × (最終終値−最初の終値) / 終値変化絶対値の総和` | <0.3 / 0.3〜<0.6 / ≥0.6 |
| 直前トレンドの整合度 | 8 点中の高値 4 点・安値 4 点について、計 6 個の差のうち①と逆方向に進んだ割合 | <2/3 / 2/3〜<1 / 1 |
| 過去 8 点の外側まで終値で突破 | LONG は過去 8 点の最高値、SHORT は最安値に対し、①内の最も進んだ確定終値が半ポイント超だけ外にあるか | True / False / 利用不能 |

終値効率は符号付きで −1〜1。①方向と逆に終値が進む場合の負値をゼロに置き換えない。TR14 は Wilder ATR ではない。①内の終値による突破を測っており、エントリー後に突破したかどうかは使わない。

## データ監査の結果（勝敗を未開示）

- 年間 440 件を ORDER と一意に結合。全 440 件の許可した時刻フィールドが ORDER 以前。
- ①/TR14・終値効率は 440 件。直前 8 点が必要な 3 特徴は 378 件で利用可能、62 件は欠損を保持。
- 画像は上位足・下位足それぞれ直前 300 本。上位足の①起点が窓外の事例は 0 件、下位足は 2 件。事例ごとの窓外フラグを表示に渡している。
- 処理前後で入力ハッシュ一致。具体的な SHA256 は `manifest.json`。
- 元の年間テストは生成ティック。今回の画像は保存した確定 OHLC と当時のイベントからの再構成で、MT5 の実画面キャプチャではない。
