# 遮断原因の診断：2024年・2026年分を確認完了

## 最終結論

遮断は二種類だった。**2024年6〜11月の無取引は、テスターの気配値が上限2.0pipsを超えていたための正常な遮断。一方、2.0pipsちょうどを小数計算誤差で落とす不具合も実在する。** API取得失敗は両期間とも0。

| 診断期間 | 判定数 | 通過 | 実際に2pips超過 | 境界誤差だけの遮断 | API失敗等 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 2024年 | 15,556 | 4,911 | 10,319 | 326 | 0 |
| 2026年4〜9月 | 7,860 | 1,414 | 4,247 | 2,199 | 0 |

原因は判定時のBid/Askを直接記録して確認した。売買用EA・Shared・パラメータは変更していない。誤遮断の修正後にトレード数や利益がどう変わるかは未検証。遮断バー数を取り逃した有効シグナル数と読み替えない。

## 2024年：長い無取引期間の原因

- 6〜11月：130記録日×60回=7,800回すべて上限超過。2pips境界誤差0、通過0、API失敗0。
- このうち7,567回（約97.0%）は23points=2.3pips。最小2.3pips、最大20.0pips。
- したがって、境界誤差だけを修正しても、この6〜11月のゼロ取引は解消しない。
- 年間326回の境界誤差は他の月で発生。
- 元の23取引の時刻・価格・ロット・SL/TP・売買損益・手数料、日別遮断数、bars/ticksが一致。診断追加による売買変更は確認されなかった。
- 純益は−337.06→−336.72、差+0.34はスワップ3.68→4.02のみ。入力163項目は運用ファイル名3項目以外一致。
- コンパイル0 errors / 0 warnings。判定記録をDecimalで独立再計算し、原因分類とSYMBOL_SPREADを全件照合した。
- 履歴品質は引き続きMIXED_TICKS。この結果はテスター内で正常に遮断した証拠であり、過去ライブ配信の正確性まで証明しない。

## 確認済み：2026年4〜9月

元EAの条件・戻り値を維持した診断版で、対象7,860回の気配値を保存した。

| 原因 | 回数 |
| --- | ---: |
| 正常に通過 | 1,414 |
| 実際に2.0pips超過 | 4,247 |
| 20points=2.0pips境界のdouble誤差だけで遮断 | 2,199 |
| 気配値API失敗・pip異常・負スプレッド | 0 |

遮断合計6,446回は元実行と一致。日別の全カウンターも一致。誤差だけの遮断は全遮断の約34.1%。本当の超過では21pointsが3,824回で最多。これは売買シグナル数ではなく、シグナル前ゲートの呼出回数。

実例（2026-04-01 07:15）：Bid158.862 / Ask158.882、SYMBOL_SPREAD=20points、pip=0.01。しかし元の `(Ask-Bid)/pip` は `2.0000000000010232` を返し、`<=2.0` がfalseになった。価格格子を用いたDecimal再計算でも分類を照合した。**少なくとも2026年にはプログラムの境界比較が原因の誤遮断が実在する**。売買用の比較処理はまだ変更していない。

## 再現性の範囲

- 8取引のEntry/Exit時刻・価格・ロット・SL/TP・売買損益・手数料は元実行と一致。
- 日別遮断数も完全一致。
- 純益は元−119.35に対し−118.66。差+0.69はスワップ7.36→8.05のみ。
- M15バー数12,575は一致。総tick数は23,565,858→23,565,855と3件減少。このため厳密な検証結果 `passed=false` を保持した。実tick補完警告はないが、履歴の完全一致とは言わない。
- テスターが返した気配値における診断。過去のライブ約定可能性や原配信の完全性は未証明。

## 実行スクリプトの障害と復旧

MT5テスト自体は完了したが、レポートPNGの保存先がWindows PowerShellのパス長上限を超えて停止し、2024年分は未実行だった。元FAILED記録を残し、保存済みのHTML/telemetry/quote CSVから解析を回収。画像4点も原名のまま拡張長パスで保存し直した。

ランナーを拡張長パスでコピーする処理へ修正し、実ファイル4点で動作確認。凍結manifest内の1件だけ指定する診断用オプションを追加し、2024年のみを再開する。2026年を再実行して結果を選び直さない。
