# M4設定のEAレビューと既存半年実行の監査

ユーザーが変更・最適化した売買用ThreeWave EAを読み、緑Wave1線とSLの違和感、勝敗の偏りを調べた。売買コードは変更せず、新規MT5テストも起動していない。

- [監査報告](../../reports/qa/three_wave/m4_review_20260926/summary.md)
- [再集計コード](../../tools/analyze_three_wave_m4_review.py)

ネイティブログの最終実行がユーザー貼付設定と一致。88取引/+450.08 USDだが5月以外は損失。起点はM4終値ピボットで、描画時刻だけヒゲ極値へ移動していた。SLは全件その終値安値−10ポイントで一致、47件は起点足のヒゲより上。M4そのものの非対応ではない。

重要なコード上の問題としてUSDJPY制限の削除、動的TFに追従しない表示名、CHoCH即時エントリーなのにWave1再突破とするCSV理由、OnInitが拒否する入力を含む最適化範囲を確認。512パス中474失敗で遺伝的探索は世代0停止。コードとテスト結果の理解を先に整え、利益だけで追加昇格しない。

H1 EMA上向きの集計差は前半に偏り、後半は逆転。相場条件の追加は見送る。今回のプラスをM4やEMA期間の個別効果へ帰属させることはできない。次は表示修復と価格ルール変更を分け、固定した少数仮説を検証する。
