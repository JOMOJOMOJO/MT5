# 3波3波 v1.0 実装と初回目視レビュー資料

ユーザー提供仕様を、新規 [Wave33VisualVerifier](../../mql/Experts/Wave33VisualVerifier.mq5) と専用Includeへ実装した。既存EA・既存の未コミット変更は保全した。作業ブランチは `research/wave33-visual/2026-10-20-implementation`。利益最適化、既存ファミリーの再調整、運用昇格は行わない。

## 実装判断

判定・型・描画・CSVを分離し、実体のある確定足だけを順に投入する。スイング足の時刻と実ティックで知り得た時刻を分離し、新しく知ったラインで過去の足へシグナルを発行しない。上位終点確定時の既存W2状態は、現在の認識時刻で観測として記録する。

両時間足、LONG/SHORT、PIVOT/TRENDLINE/先着、Fib到達と最深値、既知抵抗、H1方向、診断のみ／テスター注文を実装。初期値で深い押し・近隣抵抗・H1逆行を暗黙に除外しない。同方向1レーンの競合は黙って候補を捨てず、別候補のSKIPとして残す。手動価格は表示専用で、自動判定に入れない。

詳細な仮定・限界は [仕様ノート](../../knowledge/experiments/2026-10-20-wave33-visual-spec.md) と [検証手順](../validation/wave33-v1-visual-review.md) に集約した。

## 検証と修正

- 実CWave33Engineの合成バー試験100/100。左右2本の確定遅延、両方向・時間足・トリガー、状態遷移、深い押しの計測／除外、失効、重複足、後続データで既存アンカー・イベントが変わらないことを確認。
- XAUUSDの固定区間2025-01-06～18をreal ticksで実行。A19候補・5シグナル、B59候補・PIVOT27シグナル。注文ONはA4約定/4決済、B24約定/24決済でLONG/SHORT双方を含む。
- API返値未確認のコンパイル警告を修正。最終EA・harness・描画専用補助EAは0 errors / 0 warnings。
- 実Visual=1は最後まで実行したが、build6230でChartScreenShotがtrueでもPNGが生成されなかった。画面読み取りは許可タイムアウト。直接画像の確認を合格扱いしない。
- 代替の描画確認は通常MT5チャートで、記録イベントと判断時刻までの実XAUUSDバーを再生した。売買・シグナルの再計算はせず、実テスター画像とは明記して区別する。
- 実画像確認でオレンジ塗りと長いラベルの重なり、M5で水平線の2点が同一足に入る不具合を発見。修正方針を説明して描画のみ修正した。最終A再実行の全イベントCSVは、修正前とSHA-256一致。
