# USDJPY HL/Fib50 EA — 実装前レビュー

既存のM1/M5確定ピボット可視化を使うロング限定EAの依頼を受け、まずソース・ヘッダー・8バッファー・確定時刻・前段階の実MT5検証を確認した。インジケーターは再コンパイルで0 errors / 0 warnings。

価格を過去の候補足へ書くため、確定時刻を無視したバッファー参照は先読みになる。またM5の処理完了時刻が公開されていないため、M1新バー一回判定のEAでは共通ヘッダーによる直接検出を推奨した。

M1ブレイクをM5安値確定後に限定するか、どのM5高値を上抜き基準とするかで戦略が変わる。ユーザーが実装前の不明点指摘を求めているため、2点を質問し、その回答に依存するEA実装はまだ開始していない。待機中に状態機械と注文保護・復元設計を記録した。
