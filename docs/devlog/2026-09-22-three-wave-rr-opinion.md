# RR1改善の報告を受けた診断方針

ユーザーはRR1ではRR1.2より勝ちやすくなったと報告。今回、そのRR1テスト自体のレポート・期間は未確認。EAや設定は変更せず、既存4月14件の価格関係のみ集計した。

[価格関係の集計](../../reports/qa/three_wave/early_wave_fix/rr_geometry.json)では、エントリーから固定M5 Wave1高値までの距離をSL幅で割った値の中央値0.68R、1R未満10件、1.2R未満11件。SL幅中央値9.15pips。これはTPが前回高値突破を必要とする頻度の診断であり、その高値が実際に抵抗になった証拠や、SLが広すぎる証拠ではない。

意見は追加検証（test-next）。次は同一候補・同一SLに対する1R/1.2Rの到達順と最大順行幅をティックで調べ、損切りまでの逆行も照合する。固定候補の出口比較と、ポジション占有時間によって候補採否が変わるEA全体の比較は区別する。

現行は既にM1戻り高値突破を優先し、該当高値がない場合はM1 Wave1高値突破を使う。さらに早める必要があるなら、まずHLの右2本確認がどの程度の遅れを生むかを調べる。フィボ50%指値は良い価格で約定する可能性がある一方、時刻を早める保証はなく、未約定と反転未確認の約定が増える可能性がある。未確定HLを後から確定済みとして扱う検証は不可。

今は候補が少ないため細かい比率最適化は行わない。新しい公開用seedは作成せず、既存の初動・時系列に関する検証記録に診断を追加した。
