# quality12bを売買動作を維持して分割

ユーザーのリファクタリング依頼に対し、M15 quality12bのメインを8つのIncludeへ分割した。イベント処理をメインに残し、設定・リスク・価格データ・構造・シグナル・注文・ポジション管理・診断の所在を明確化した。再結合したソースは元とバイト単位で一致し、163入力を維持、コンパイルは0 errors / 0 warnings。[検証記録](../../reports/qa/quality12b_refactor_20261006/summary.md)。速度改善や戦略修正は含めていない。

研究バッチは2022年の1件のロット差で停止した。正常確認できた181件だけを[途中結果](../../reports/qa/quality12b_context_exit_20261006/interim_summary.md)へ分離。過去年の費用差は確認したが、ロット差の因果関係は未確定。研究観測処理を外した2022年の隔離対照テストを準備し、静的同一性と実行時同一性を区別する。[対照パッケージ](../../reports/qa/q12_refactor_check_20261006/manifest.json)。

検証スクリプトには明示的なBASELINE_RECHECK用途を追加。生成tickを許容するのは実行一致の比較だけで、既定のリアルtick品質判定は緩和しない。MT5起動後は待機せずユーザーへ返す。
