# Wave33: 接続する逆①を両側見送り、文字の衝突を整理

ユーザーは、古い候補だけ取消されて新しいショートが残る動作を確認した後、接続する①は両方見送ることと、画面上の文字の重なりの改善を指示した。

[固定仕様](../../knowledge/experiments/2026-10-25-wave33-connected-pair-and-label-plan.md)に従い、現行の因果的な接続判定を変更せず、双方未発注なら原子的に無効化するヘルパーとEngineの既定OFFフックを追加した。診断EA v1.84は新入力を初期ONにし、両IDへ `CONNECTED_OPPOSITE_W1_BOTH` を記録して監視・発注を終了する。送信中・保有中は保護し、既存の逆①後の利益決済を維持する。

表示はEA専用アダプタと独立LabelLayoutを使う。元の価格・時刻は固定し、文字だけを短縮してピクセル間隔で配置、有限の引出線を結ぶ。共通候補IDで各種ラベルを照合でき、元高安の時間足・日時・価格は残す。レイアウトOFFや画面移動でも元座標へ戻せるよう管理する。

ユーザー画像は実ログで特定できた。2025-01-14 22:15、旧LONG終点と新SHORT起点が21:35 / 2676.33を共有する。元動作の22:39ショート注文に対し、新規則は22:15で両候補を終了する。[QAと記録値](../../reports/qa/w33_pair_layout_20261025/README.md)へ根拠を保存した。

原版EAソース・EX5と共通Displayは維持した。Engineの新フックは本件の意図的な変更であり、既定OFF・旧Engineイベント比較により原版への自動適用を防ぐ。①/Fib/高安帯/往復/SL/TPを同時に調整しない。今回の変更を利益改善の証拠とはしない。

表示の修正は売買ロジックの改善と区別して検証した。画面外へ移動した文字のコンパクトフォントを元の書式として誤保存する不具合がレビューで見つかり、元書式の保持・復元を修正した。実画像で価格軸側の文字切れも見つかり、判断点を動かさず文字配置だけ右端・上端の余白を確保した。

最終は機能846項目・通常チャート描画27項目・CSV別監査202項目が失敗0。両側OFFの旧Engine比較は912イベントの全CSV列が一致。EA・ハーネス・描画用EAは各0 errors / 0 warnings。[最終検証](../../reports/qa/w33_pair_layout_20261025/final_verification.json)と[QA詳細](../../reports/qa/w33_pair_layout_20261025/NATIVE_QA.md)を参照する。

この環境のTesterは画像出力と価格固定範囲変更に制約があったため、表示は発注機能のない専用通常チャート・合成OHLCで検証した。実バックテスト画像や実際の利益を示す証拠とは区別する。headlessの表示未確認をPASSと数えず、途中の試行も保持した。
