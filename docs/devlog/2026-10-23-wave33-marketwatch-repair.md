# Wave33 v1.71：全気配値銘柄モードの初期化失敗を修正

ユーザーの2026-10-22ログでは10パスすべてがOnInit code1。全気配値銘柄モードもMT5内部では最適化扱いで、v1.70の実行禁止に当たっていた。事前の[修正範囲](../../knowledge/experiments/2026-10-22-wave33-marketwatch-repair.md)に従い、初期化・注文・逆①待機/利益決済のテスター文脈判定を統一した。新入力 `InpAllowTesterBatchRuns=true`、通常口座の発注は禁止のまま。描画は一括パスで実効OFF、Common出力は排他的なタグ予約で分離する。

既存戦略ヘッダー7件と他EA2件は変更なし。RR、抵抗、①延長、逆①利益決済の定義を変えず、接続した反対①の新規フィルターは保留を維持した。コンパイル10対象0errors/0warnings、新ハーネス38項目PASS。v1.70対v1.71の単銘柄28チェックは差分0、Model4一括内XAUUSD+は単銘柄の全1,240イベント・原本足・逆①監査ティックと一致。

最初のModel4一括はデータ同期で上限に達し、未完了として保存。Model1の固定入力一括はネイティブ10パス、14注文/約定/決済が完了した。モデルを変えた損益差を戦略差や完全一致と呼ばない。選択datにある14名称には換算銘柄も含まれ、ネイティブの実対象数と同じだと誤認してはいけない。原runnerのREVIEW_REQUIREDは保持し、後続監査で観測10パスの完了・CSV整合性を確認した。実ティック執行・利益・動画一致は今回の合格対象ではない。

v1.71 EX5とA/B SETを主端末に配置し、主端末は停止していない。検証結果、未完了記録、データ不足3銘柄、AUDUSD対象外の未確定事項、XML空報告、SHA256と再実行方法は[QA記録](../../reports/qa/w33batch/README.md)へ集約した。操作は[注文手順](../validation/wave33-tester-orders.md)。今回は互換性修正のため、記事seedは追加しない。
