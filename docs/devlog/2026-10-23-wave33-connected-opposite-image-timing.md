# 接続逆①画像：候補と確定の時刻差を確認

ユーザーは連続する逆方向①がある場合、最初のショートをキャンセルできるか質問した。直近Common CSVからXAUUSD+、2023.01.05、M5/M1の同一事例を特定。反対①候補18:10、ショート発注18:25、実約定18:25:07、反対①確定18:30。旧ショート終点と新ロング起点は17:35・1825.03で一致した。

確定した青①を条件にすると、この注文の見送りには遅い。共有終点から新しい逆①候補が出た時点で、未発注の旧候補だけを終了させる条件なら未来情報なしで可能、と整理した。既約定の取消と決済を区別し、現行の逆①利益決済を独立確認。新規フィルターは実装せず、EA・RRを維持した。

元画像の①足位置18:15を、EAが知った18:30と混同しない。反対候補が失効する場合にも旧方向を見送る差があるため、一例で採用・改善を確定しない。[該当候補の全イベントと時系列](../../reports/qa/w33join/README.md)。今回の結果は当該画像の因果性確認で、年間の追加最適化ではない。
