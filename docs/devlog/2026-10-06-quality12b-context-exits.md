# quality12bの上位足環境と出口を研究版で比較

ユーザーの要望は2025年依存の緩和、以前の上位環境認識の再利用、H1/H4等に応じたSLTP/RRの検証。まず元Entryを固定した記述分類と出口の対応比較を実装した。

[事前固定計画](../../reports/qa/quality12b_context_exit_20261006/plan.md)。M15実行のまま、M15/H1/H4環境を保存。元M15共通クラスを凍結し、時間足一般化との一致をEntry毎に監査する。現行EAとSharedは不変。研究ソースは0 errors/0 warnings、Pythonテスト計30件合格。

既知のスプレッド境界修正を混ぜるとEntry母集団が変わるため今回は据置。元約定との一致が必須。出口は固定SLでRR1/1.5/2と、H1/H4安値SLのRR1.5。M1経路でのshadow近似なので実注文の収益/実行可能数と混同しない。研究を終えた時点で未検証事項と年別傾向を再レビューする。

隔離MT5を起動後、ユーザー希望に従い待機せず終了する。運用中のチャートは操作しない。
