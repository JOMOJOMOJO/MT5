# 3波初動を逃した候補の再利用を確認

ユーザー画像のUSDJPY 2016-05-23 16:50売りを元CSVと照合し、09:35のW2高値から7時間15分後の別の小さなM5転換を採用していることを確認した。売値109.438は元のW1安値109.680をすでに下回る。5月12日と同じ型の再現性不足である。

原因は、古いW1/W2を固定したまま、以後の最新下位構造を繰り返し探索する候補管理。現EAの工学的PASSを3波3波の再現性PASSとは扱わない。[再現性の不足と次の設計原則](../../knowledge/experiments/2026-10-21-wave33-reproduction-gap.md)へ判断を保存し、[当該事例の原本CSV・時刻](../../reports/qa/wave33_visual_20261020/usdjpy_20160523_wave_mismatch/README.md)へ接続した。

09:35の高値へ遡った発注を解決策にしない。現W1確定認識は09:45である。今回は波の対応と候補終了の不足を説明し、売買ロジック・ユーザーのテスター・入力は変更していない。
