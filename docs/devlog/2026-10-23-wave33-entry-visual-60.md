# ①と直前ジグザグの勝敗非表示60画像レビュー

ユーザーの依頼により、勝ち/負け各12例の提案を各30例へ増やし、2020年v1.80の既存440取引から合計60例を観察した。A/B・方向・勝敗を8層に分け、層内の時系列等間隔位置とseedで固定した。損益額や見栄えで事例を選ばない。[事前計画](../../knowledge/experiments/2026-10-23-wave33-entry-visual-60-plan.md)。

[主成果物・全60画像](../../reports/qa/w33entry60/README.md)に、前後の原本データ、盲検分類、注釈固定前のハッシュ、勝敗開示後の集計を分離して保存した。各担当が奇数/偶数30例の全個別画像を確認し、rootは事前固定6例を別に確認した。エントリー後の足・年月日・勝敗を図から除いた。画像はMT5直接スクリーンショットではなく、原本OHLCとORDERスナップショットの再構成。

画像では往復の多い①が勝ち8/30・負け17/30に見られた。しかし固定した終値効率では同じ関係を再現せず、数値閾値を作り替えていない。主項目の前高安範囲終値突破は、年内126例で平均+0.013R、内側252例で−0.118Rだが、勝率は双方44.4%。負けの割合を下げる条件とは断定しない。画像標本では平均R差の向きも逆で、標本と全件・残り380例を独立検証とは扱わない。

別途、結果を伏せた観察中に、①起点より後に逆側の極値がある例を複数担当が発見した。後から追加した工学監査で37/440例を確認し、35例は候補ブレイク足より前、2例はその足だった。元価格の誤記や未来情報ではなく、最後の確定スイングを起点へ採用し、候補以前の区間極値へ起点を更新しない定義で説明できた。37例は16勝21敗でA/Bの損益方向も逆なので、一律除外は採用しない。

独立監査はrawpivot134,747観測の左右2本再構成一致、60packet381,336チェック、選定60例の再現、全PNG/注釈/EA関連12ファイルのハッシュ維持を確認した。[監査一覧](../../reports/qa/w33entry60/audit/README.md)。ギャラリーはローカル読取専用HTTPとオフラインHTML/ZIPで用意した。ブラウザー自動操作はタイムアウトしたためUIクリック試験は完了扱いにせず、HTTP配信・60リンクと全PNGの確認に範囲を限定する。

EA・設定・年間原本の変更、新MT5実行、フィルター採用はなし。次に点検するなら「確定スイング起点」と「候補までに既知の区間極値」を並べ、①/Fibの意味を人の認識と照合する。収益改善として先に修正しない。[内部知見](../../knowledge/backtests/2026-10-23-wave33-entry-visual-60.md)、[記事の種](../../content/seeds/2026-10-23-wave33-chart-shape-and-entry-definition.md)。
