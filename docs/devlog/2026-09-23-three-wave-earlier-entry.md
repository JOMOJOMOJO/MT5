# M1転換・HL確定で入口を早める比較

## 依頼と固定条件

7:38付近の底そのものを後知恵で買うのではなく、M1の転換が分かった時点、または7:41のようなHL確定時点で買えるかを検証する。M5起点割れの無効化は継続。新しいオシレーター等は追加しない。

比較前に[検証計画](../../reports/qa/three_wave/entry_research/plan.md)を固定。RR=1、Equityの1%リスク、15分クールタイムで統一する。CHoCH直後にはHLがないので転換起点をSLに使い、現行入口でも同じSLを使う対照を置く。

## 実装

- 本番EA/インジケーターの既定動作は維持。原本のハッシュとコピーを検証フォルダに保存。
- `tools/swing_structure/build_entry_research.py` が原本から再現可能なテスター専用EA・構造ヘッダーを生成する。
- `InpEntryResearchMode=0`: 現行、`1`: M5が50%以上押した後のM1 CHoCH、`2`: M1 HL確定時。
- モード1の50%は、確定済みM1転換安値がM5 Wave1の中間以下で、起点より上という意味。エントリー価格が中間以下である条件や50%指値とは異なる。
- モード1には存在しないM1 Wave1/HLを埋めず、空欄のままログに出す。SLは転換安値を使用するよう初期化で制限。
- 実口座・通常チャートでは起動を拒否。指標照合は現行インジケーターとの意図的な差があるため無効にし、独立OHLC監査と合成テストを使用。

## 検証

合成16件合格、EAと検証スクリプトはコンパイルエラー・警告とも0。[証跡](../../reports/qa/three_wave/entry_research/)

短期2回、比較4回、別期間2回の実MT5テストを完了。[最終レポート](../../reports/qa/three_wave/entry_research/summary.md)を参照。全案が採用基準未達のため、標準EAは変更せず、テスター専用検証版を保存した。

比較期間では早期HL、CHoCH50とも赤字で採用基準未達。CHoCH50は現行より損失・DDが小さく、取引数も増えたため、別期間を見る前にこの案だけを固定して5〜7月を比較すると追記した。採用条件は緩和せず、別期間だけ良くても採用しない。以後の探索・条件追加はしない。

別期間のCHoCH50は69取引、-901.41 USD、最大DD13.93%。現行55取引、-869.53 USD、DD11.76%より取引数だけ増え、総損益・DDは悪化。今回の早期化サイクルは不採用で終了。現行も赤字であり、現行維持は収益性の認定ではない。
