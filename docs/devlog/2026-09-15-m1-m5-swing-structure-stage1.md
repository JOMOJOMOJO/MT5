# M1/M5確定ピボット可視化 — 第1段階

新規インジケーターとして内部波M1と親波M5を同一M1チャートへ表示した。左右の確定足に対する厳密な高安比較を使い、同値は除外する。既存EAと売買処理は変更していない。

ピボット足時刻と利用可能な確定時刻を分離し、追記型の記録から矢印・線・8バッファーを構成した。同種連続や同一足の高安同時成立は点を残し、解釈が必要な接続を省く。初回の別時間足履歴は非同期に読み込まれるため、ティックがなくても1秒タイマーで準備を再試行する。

実MT5でM1/M5の182ピボット、時刻マッピング、追加10本後の364バッファー値保持を確認。検証スクリプト29項目合格、コンパイルは本体・検証用とも0 errors / 0 warnings。表示画像も確認した。詳細、制限、再現手順は[QA記録](../../reports/qa/swing_structure/README.md)、表示は[チャート画像](../../reports/qa/swing_structure/chart.png)。

入力変更や再起動後の永続的な不変性は対象外。同一稼働セッション中の既確定点を保持する。候補足へ遡及表示した値を将来の検証で使う際には確定時刻による制限が必要である。第2段階のA/B/Cやエントリー候補には進まない。
