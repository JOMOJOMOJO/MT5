# 往復診断を任意の発注フィルターへ接続

ユーザーは診断指標で該当取引を止める設定を希望し、実装を明示的に依頼した。`Wave33ChopDiagnostic` をv1.82へ更新し、`InpSkipChoppyWave1=false` を追加した。ONならシグナル直前の確定情報でCHOPPY（既存の逆行合計÷①幅が0.5以上）となる候補を発注前に終了する。指標自体は変更していない。

除外は `CHOPPY_WAVE1`、根拠は `CHOP_ENTRY_FILTER` へ記録する。診断OFFでもフィルターONなら観測を継続する。判定不可は理由を残して従来条件へ通す。見送ったシグナルが緑のENTRYに見える点を避け、日本語の理由をEA専用アダプターで表示する。共有Displayや元EAのソースは変更しない。

検証と操作方法は[QAレポート](../../reports/qa/w33chop_filter_20261024/README.md)、範囲は[固定計画](../../knowledge/experiments/2026-10-24-wave33-chop-filter-switch.md)。元の診断・年間結果を保持し、[前回の分類再現失敗](../../reports/qa/w33chop/README.md)を利益改善や戦略採用の根拠へ読み替えない。

比較用プリセットは両時間足のON/OFFを用意し、注文をテスター内で有効にした。ユーザーはテスターでEAを選び直し、ONを読み込めば比較できる。

新EAと実EAラッパーハーネスは0 errors / 0 warnings。MT5で5設定・694項目PASS、イベントの独立照合36項目PASS。OFFでは全12候補が従来の発注OFF分岐へ進み、ONではCHOPPY4候補を除外し、他8候補は同じ分岐へ進んだ。発注ONの専用試験でもCHOPPY4候補は全てSKIPとなり、注文イベント0。合成入力の動作検証であり、成績の改善や旧版との約定損益一致を示す試験ではない。
