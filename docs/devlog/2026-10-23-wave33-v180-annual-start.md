# Wave33 v1.80の1年間テストを起動

ユーザーがv1.80の年間バックテストと起動後の作業停止を依頼した。前回との比較が可能な2020年・XAUUSD+・A/B・初期5,000 USDを採用する。承認済みの2変更をONにし、RR入力1・risk1%などは維持する。[年間実行条件と保存先](../../reports/backtest/runs/wave33_v180_2020/README.md)を固定した。

検証済みソース/EX5/全ヘッダーのハッシュ確認後、PowerShell7から専用隔離ランナーを起動する。元の通常MT5は停止しない。実ティック欠落の可能性を残し、開始を完了や収益改善と混同しない。

起動を確認した時点でエージェントの作業を終了する。テスターはA→Bを継続し、原本・完了/失敗状態を保存する。分析・追加検証・最適化は次のユーザー連絡まで保留する。
