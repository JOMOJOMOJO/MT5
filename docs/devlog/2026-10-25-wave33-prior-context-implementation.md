# Wave33: 以前の上位足高安帯を別モジュールで実装

ユーザーは①自体の認識を維持しながら、過去の高値付近で再び買っている相場環境を反映したいと指示した。以前の調査は[高値の因果的復元](../../reports/qa/w33context_20261025/README.md)と[方向と位置の違い](../../knowledge/patterns/2026-10-25-wave33-direction-and-location.md)。これに対して、H1方向による一律除外ではなく、以前の高安帯への再接近と最終TPの関係を観測する独立機能を追加した。

## 変更

- `Wave33ChopDiagnostic` を v1.83 に更新。新規 `PriorContext.mqh` に計算・観測キャッシュ・CSV・有限描画を分離。
- 以前のM15/H1高安は公開済みPIVOTのみ、確定足はFeedClosedの受理済み列のみ。最終Plan後、SIGNAL公開前に判定する。
- ①値幅の上下各5%を比較用の初期帯とした。終点が帯内・entry未突破・最終TPが帯の先・当該時間足終値未突破ならBLOCKED。既知の阻害候補を別候補で隠さない。
- 診断true、見送りfalseが初期値。ONなら `PRIOR_LEVEL_RETEST` で発注前に終了し、未発注枠を解放。データ不足は理由を記録して許可する。
- 元高安へ「事後参照・時間足・位置日時・価格」を表示。シグナル以降の帯は下位足12本分。元高安の確定時刻も保存し、無限の水平線は増やさない。
- 42入力のA/B比較プリセットを追加。従来の往復除外はOFF、今回の見送りON/OFFとrun tagだけが組内で異なる。

固定仕様は[実装前計画](../../knowledge/experiments/2026-10-25-wave33-prior-context-plan.md)、コード・スナップショット・コンパイル・ネイティブQA・独立監査は[今回のQA](../../reports/qa/w33_prior_context_20261025/README.md)を参照。

最終検証はEA/ハーネスとも0 errors / 0 warnings、ネイティブ1,470項目・CSV別監査67項目が失敗0。両時間足とLONG/SHORTで、ONのみ該当4件を除外し、8件を許可する。OFFは12件が従来の注文無効経路へ進む。予定ENTRY/SL/TPは同一。原版等12ファイルと往復計算モジュールの変更なしをハッシュで確認した。描画は実オブジェクト数と有限座標を読み戻し、最終外観の目視とは区別する。

## 判断と範囲

①/Fib/往復計算や原版EA・共有Engine/Display等は維持する。ダブルトップの完成を事後の下落から認定する方式は採らない。M15/H1の同じ市場変動は独立した反発回数と数えない。5%の帯は初期仮定であり、この例に合ったことを収益改善の証拠としない。

今回は機能・時点整合性を検証し、年間バックテストや未使用期間の調整を行わない。最終画面での読みやすさはビジュアルテスターでユーザーと照合する。古い消化済み高安が候補に残ること、起動後の前向きウォームアップであることは限界として残す。

外部向けの新規seedは作成しない。再利用できる発見は既存の[方向と価格の位置](../../content/seeds/2026-10-25-trend-direction-and-price-location.md)に集約され、今回追加されたのはその実装と技術検証である。
