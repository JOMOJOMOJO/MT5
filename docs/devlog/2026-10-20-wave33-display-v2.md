# 3波3波の表示を山谷と波の順序で読める形に変更

ユーザーから、左上の文字がローソク足を隠し、色分けだけでは意味を追えないとの指摘を受けた。指定された `MQL5/Indicators/MultiTF_3WaveIn3Wave_Visualizer_v1.05_InvalidationReset.mq5` の確定pivot連結を参照し、新規EA [Wave33VisualVerifier](../../mql/Experts/Wave33VisualVerifier.mq5) の描画だけをv1.10へ改訂した。

左上の大きい情報欄を廃止し、初期表示はOFF。上位足と下位足の確定高安を実際の足位置に置き、細い破線で結ぶ。青い太線の「① 第1波」、オレンジの「② 押し・戻り」、緑のENTRYを主な目印にし、詳細ラベルは任意表示へ移した。W2更新履歴は小さい点で残し、時刻と理由はtooltip・CSVへ保持する。見送り文字はW2文字と反対側へ置く。

山谷を結ぶ脚は認識後にだけ生成し、高安の足時刻・表示位置・known_atを区別する。上位足の高安の横位置調整は、既に閉じた下位足で行う表示専用処理。水平・転換判定線は引き続き既知時刻を左端とする。同一足の高安の順序は推測せず、あいまいな連結を作らない。レビューで見つかった「同一足H/L処理が以前の別の線を消す」問題は、その足・時間足の該当線だけを対象にする修正で解消した。

Engine・Types・Ledger・参照インジケーターのSHA-256は変更なし。固定XAUUSD区間のMT5 real tick回帰は19候補・5シグナルで、全1499行のイベントCSVが改訂前とバイト一致。最終EAコンパイルは0 errors / 0 warnings。初版の100件のエンジン試験結果は既存資料に残し、今回は描画の変更に対応するコンパイル・回帰・画像確認を実施した。
