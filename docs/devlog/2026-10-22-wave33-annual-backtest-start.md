# Wave33 v1.70の1年バックテストを起動

ユーザーは連勝期・連敗期の違いを後で分析するため、1年分のバックテストと、起動後の作業停止を依頼した。年の指定がないため直前の2020年を採用し、A/Bを別々に実行する。戦略・RR等の調整、最適化、連勝連敗の分析は行わない。

実行条件と保存先は[年間実行記録](../../reports/backtest/runs/wave33_v170_2020/README.md)。検証済みv1.70のソース・ヘッダーハッシュを起動前に確認し、隔離端末で両組を順次実行する。完了状態とエラーはランナーが自動保存し、ユーザーが戻った時点で原本の充足と連続損益を確認できるようにする。開始時点では完了・利益・実ティック充足を主張しない。

最初のWindows PowerShell 5起動はGet-FileHashを解決できず、テスター起動前に終了した。失敗ログをfirst_attempt_*へ残し、現環境と同じ同梱PowerShell 7から再起動した。EAや比較条件の変更はない。
